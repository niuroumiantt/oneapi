# OneAPI 模型 API 交易平台

OneAPI 是一个面向个人开发者和企业客户的模型 API 商业平台。本仓库保存产品设计、业务规则和后续实现。`oneapi` 是本项目的仓库名称，不代表已经选定同名第三方网关或最终品牌。

## 已确认的产品方向

- 一个产品覆盖中国与美国市场，首期先在中国落地，首批模型家族为 DeepSeek 和 GLM。
- 供应商接入、质量评估、模型市场、登录权限、个人付费、企业采购、PO 与发票、客户控制台、员工运营后台都纳入总体设计。
- 推广员、代理商、分销商、区域总代理分别建模；推荐优惠与渠道佣金分别记账。
- 前台采用简洁、精致且具有色彩的设计；运营后台强调信息密度和操作效率。

## 工程原则

1. 代码职责清楚，每段代码都有可说明的用途。
2. 名称直接反映业务含义，统一术语、字段、文件和事件命名。
3. 优先复用成熟组件，集中自研定价、结算、渠道和合规等自身业务规则。

## 当前阶段

2026 年 11 月 6 日开始重建设计基线。当前是产品与架构设计阶段，尚未上线运营；具体商业条款、供应商授权、各地区合规及软件许可证均须在上线前落实。

本仓库不默认采用其他既有项目的实现。后续设计文档会明确已确认需求、建议方案和待决定事项。
