# 视觉方向与页面设计

0.3 更新：[模型广场与接入向导](phase-1/02-models-and-agent-onboarding.md) 和 [供应运营后台](phase-1/07-supplier-operations.md)。本页保留总体业务边界，首期范围以新入口为准。

## 整体方向

建议采用“珍珠白与光谱色”作为首版方向：浅色底、精确排版、适量留白、清晰层次，以及蓝、青、紫和少量暖色。借鉴苹果产品的克制与精致，不照搬品牌资产。装饰主要集中在官网和模型卡片，交易及运营页面保持可读。

| 方向 | 视觉特点 | 最适合的位置 |
| --- | --- | --- |
| A 珍珠白与光谱色 | 白与浅灰基础，蓝青紫作分类色，轻阴影与圆角 | 推荐默认，覆盖官网和控制台 |
| B 石墨灰与电光色 | 深灰基础，亮蓝与薄荷绿强调，控制发光效果 | 后续可选开发者深色主题 |
| C 暖白与企业蓝 | 暖白、海军蓝和少量橙色，可信、稳重 | 企业销售材料与采购页面 |

只维护一套组件系统，通过语义 token 和主题变化形成风格，不为三种方案复制三套前端。已生成的概念图用于确认 A 方向的前台与后台感觉，图中数据和通道均为示意，不能当作已经实现的功能或真实供应商成绩。

## 视觉参数建议

| 元素 | 建议 |
| --- | --- |
| 页面底色 | #F5F7FB |
| 卡片 | #FFFFFF，边界采用浅灰 |
| 主文字 | #111827 |
| 辅助文字 | #64748B，实际小字号验证对比度 |
| 主操作 | #2563EB |
| 模型分类色 | 青 #06B6D4，紫 #8B5CF6，蓝 #2563EB |
| 状态 | 绿成功、橙待处理、红风险，同时配文字和图标 |
| 官网圆角 | 16–20 px |
| 控制台圆角 | 8–12 px |
| 后台表格行高 | 紧凑模式约 40 px，舒适模式约 48 px |
| 数字 | 等宽数字、金额右对齐、明确单位与币种 |
| 字体 | 本地系统字体和中文后备字体，避免依赖在目标地区不可用的远程字体 |

这些是设计建议值，开发时仍需验证键盘操作、缩放、颜色对比、焦点状态与触控目标。紧凑不是把字号缩到难以阅读；移动端使用更适合触控的布局。

## 官网和模型市场

首页依次说明产品价值、首批模型、服务与数据条件、接入方式、企业采购和服务状态。主要入口为“查看模型”和“开始接入”，而不是一上来展示大量内部术语。

模型列表提供卡片与表格视图。卡片解释用途，比较表展示精确属性。模型详情固定展示价格单位、地区、能力、限制与更新时间。首期为 DeepSeek、GLM 两个家族各设清楚的入口；未售卖能力不使用暗示可用的按钮。

地区选择器和语言选择器分开。当前地区、币种和账户类型在页面稳定位置可见。切换地区时清楚说明进入相应合同和账户环境，不能把美元展示理解为余额兑换。

## 客户 Dashboard

首屏让用户回答六个问题：我还有多少额度；今天花了多少；哪些项目在花钱；调用是否健康；是否接近预算；有没有需要处理的账单或安全事件。

首屏建议包含实付可用额度、赠送可用额度、在途预占、当期消费、成功率和最近错误摘要。消费趋势注明账期与时区，按项目/模型/Key 切换。费用为结算值还是估计值要清楚标识，避免把实时预估当最终账单。

主要导航为总览、项目与 API Key、用量与费用、模型、账单与支付、团队、推荐奖励、支持。每张图表都能进入对应明细；明细有筛选、导出、请求标识和费用解释。

新用户采用短路径：建立项目 → 创建 Key → 展示可复制请求示例 → 发出首次请求 → 显示实际费用。Key 创建后仅显示一次，撤销和轮换流程清楚。生产权限与试用环境有明显区别。

## 企业控制台

在个人能力上增加组织切换、成员角色、部门/项目预算、采购审批、报价、合同、PO、信用额度、账期、发票和回款。

企业财务视图重点是可用信用、未开票消费、应付账单、已付款与未核销款。开发者只看获准项目的 Key 和用量；不默认展示企业合同底价和全部发票资料。

采购页用明确状态串起一份交易：待审批、合同生效、PO 有效、服务使用中、待付款、部分付款、已结清。商业账单、税务发票和付款凭证各有名称与下载入口。

## 渠道控制台

推广员看到推荐链接、有效归因、已消费金额和佣金状态。代理商看到客户报备、报价权限、销售进度和获准客户范围。分销商看到批发商品、主账户额度、子客户预算及对账。区域总代理功能按合同逐步开放。

后台避免用一个“代理等级”页面混合上述关系。账号当前合作身份、适用地区、合同和收益方式应当可见。

## 高密度运营后台

后台首页以异常和待办为中心：待审核客户、即将过期供应商授权、用量差异、失败退款、待结佣金、低毛利商品和异常流量。大幅宣传性卡片不占据关键操作空间。

供应中心首期有六个视图：供应总览、供应商档案、供应产品、采购账户与资源、通道与质量、采购与对账。总览突出资金/容量不足、故障、到期与账单差异，帮助员工确定下一项动作。

供应产品列表默认列为供应商、型号/版本、区域、授权、健康、价格版本、容量压力和最近异常；侧边详情查看完整合同、计量和依赖。资金表显示余额/资源包、到期、来源和更新时间；质量表显示样本量、成功率、p95 首个有效内容时延和错误分类。筛选和列设置可以保存；数量增加时采用服务端分页与必要虚拟化。无数据时显示未知，状态除颜色外也有文本。

点击行时打开侧边详情，保留原来的筛选和滚动位置。详情包括合同证据引用、价格历史、质量、故障和操作记录；敏感凭据只提供轮换入口。

支持键盘快捷键、快速搜索、批量操作预览、可复制标识、导出和固定表头。高风险批量动作先说明影响对象和数量，执行后显示逐项结果；不能用一条成功提示掩盖部分失败。

员工管理显示岗位、范围、MFA 状态、最近访问、权限到期和交接事项。财务审批列表可以从总额下钻到每笔分录，修改原因和审核记录随单可见。

## 页面验收

每页至少有加载、空数据、权限不足、失败、成功和部分失败状态。充值结果区分处理中与已确认；费用明细区分预估与已结算；推荐奖励区分待观察、可结算和已支付。

面向客户的文案解释业务影响。数据库、队列、供应商内部实现等细节不挤入正常购物流程。确实影响客户决策的数据处理地区、限制、价格和账期则要直接展示。
