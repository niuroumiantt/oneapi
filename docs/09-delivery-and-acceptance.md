# 实施阶段与验收

## 阶段 P0 设计冻结与接入验证

交付：经营与销售模式、核心术语、页面线框、模型供应商授权清单、地区策略、价格与计量合同、网关候选验证、金额精度及状态机、支付测试环境。

验证两家实际获准上游的普通、流式及首期售卖能力，确认 usage 含义、终止行为、成本证据和数据路径。采用哪个网关在这一阶段决定；不能用文档声称支持来替代实际验收。

这一阶段也确认谁是首批客户、可获采购价与预期消费、首个收款主体、是否具备中国上线条件。产品开发与供应商、支付和法律准备并行。

## 阶段 P1 中国区受控上线

交付个人与企业预付、组织/项目/Key、DeepSeek 与 GLM 核准商品、真实收款、预算预占、用量结算、退款、基础开票流程、员工权限、供应商监控、对账与单层推荐。

代理和分销首先保留协议与客户归属模型，可通过少量审核操作试点；暂不开放任何人自助建立多级网络。关键交易必须真实闭环，后台辅助处理允许存在，但有状态、负责人和审计记录。

邀请有限客户使用，设置调用及充值上限。先观察完整账期的用量、成本与支付对账，再扩大规模。不能以支付沙箱或静态页面代替已经上线的收款服务。

## 阶段 P2 企业采购与渠道增强

交付报价、合同、PO、成员角色、审批预算、经过审核的授信/账期、部分回款核销、企业 SSO、代理客户报备、分销主子预算、渠道对账与佣金冲回。

真实企业采购和渠道协议是输入，不能按想象开发无限灵活的合同系统。优先把第一批客户共同需要的流程做稳定。

## 阶段 P3 美国区与规模化

完成美国经营、供应链、数据、税务与商户准入后部署独立区域栈。审核实际可售模型服务，不默认复制中国供应商清单。验证日志、客服、运维和备份都遵守批准路径。

根据真实负载拆分热点：请求计量、账本、分析或异步任务。只有发现明确瓶颈和收益才引入复杂流平台、分析库或更多独立服务。

## 上线必须验证的场景

| 场景 | 验收结果 |
| --- | --- |
| 同一支付通知重复到达 | 一笔真实支付只产生一次应有入账 |
| 支付与退款通知乱序 | 通过状态和主动查询恢复，不覆盖新状态 |
| 余额不足时大量并发请求 | 预占总额不超过可支配预算或明确授信 |
| 用户退款与在途调用并发 | 可退来源正确，不能同时退款和继续占用同一资金 |
| 流式断连或缺少 usage | 进入可追踪状态，费用可核对，不捏造计量 |
| 网关成功后进程崩溃 | 使用证据可恢复，未决请求有补偿处理 |
| 上游重试或用户重试 | 尝试与逻辑请求区分，客户计费符合公布规则 |
| 价格更新与跨日请求 | 使用正确生效版本，历史费用不被改写 |
| 缓存与推理 token | 按上游含义计价，没有重计 |
| 合同价与推荐折扣重叠 | 按版本化优先级处理，不意外重复优惠 |
| 退款发生在佣金支付后 | 生成冲回及追回/抵扣记录 |
| 企业提交 PO | 经过授权和授信流程，不直接视为已付款 |
| 分销商分配子额度 | 总授权不重复创造现金或信用 |
| 其他组织请求对象标识 | 后端拒绝跨租户访问与数据导出 |
| 员工离职或 Key 吊销 | 会话和调用权限在约定传播期限内撤销 |
| 美国通道不可用 | 不自动回落到未经批准的中国路径 |
| 数据库恢复 | 可证明恢复后账本和请求关联仍一致 |

## 服务与经营指标

分别设定平台自身与上游端到端指标。设计目标可从平台可用性 99.9% 起讨论，但必须注明测量边界、维护窗口和依赖，压测和试运营通过后才写成对外 SLA。

关注每百万 token 的实际贡献毛利、供应商成本偏差、已收款消费、退款拒付率、待核对费用、渠道获客成本、真实留存、请求成功率、p95 首 token 时延和工单解决时间。充值总额、注册数和调用次数不能单独证明业务健康。

容量规划按峰值并发、平均输出长度、流式连接数和账本写入量测量，不凭预设“百万用户”直接设计大型微服务集群。备份目标和恢复目标在首批客户承诺前确定并验证。

## 人员与周期

截图中的完整团队更适合多地区、规模化经营。首期可从约 6–8 名核心人员讨论：产品负责人/产品经理、技术负责人、前端、后端计费与集成、网关/平台能力、测试；设计、运维、安全、法律和税务按工作量采用专职或顾问。岗位可兼任，职责和审核独立性不能省略。

时间只作规划估计：P0 约 2–3 周，P1 工程约 6–10 周，P2 约 4–8 周。假设团队经验匹配、需求稳定、供应账号和支付测试条件可用；不是承诺工期。实际商用日期取工程、供应授权、支付审批和地区合规等条件全部满足的较晚日期。美国区不承诺从中国上线日起固定几周必然开放。

## 当前交付边界

当前交付是设计基线、业务规则和视觉方向，尚未建设生产网站、接入真实付款或运行模型调用测试。下一阶段从 P0 开始，以网关、金额和地区边界验证驱动实施。
