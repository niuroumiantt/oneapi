# 供应商 API 验收台

入口：员工登录后，在“供应与验证”打开 `/api/staff/lab/console`。页面只向 `platform_admin` 和 `supply` 岗位开放；它是内部工具，不是客户模型广场。

## 当前可运行流程

1. 运维设置 `SUPPLIER_LAB_SECRET`（至少 32 字符，稳定保管）和 `SUPPLIER_LAB_ALLOWED_HOSTS`（逗号分隔的精确主机名，默认只允许 `api.deepseek.com`）。重启服务并运行数据库迁移。切换加密密钥前必须先安排凭据重录或迁移；直接换密钥会使已保存 Key 无法解密。
2. 供应运营分别登记供应商端点与官方对照端点，填入 HTTPS Base URL、实际模型 ID、测试 Key、合同采购输入/缓存输入/输出单价（人民币每百万 Token）。Key 只在提交时出现，数据库保存 AES-256-GCM 加密值；页面只返回指纹。同一 Key 支持多个型号时，用“同一 Key 下新增型号”复用已保存的加密凭据，并为每个型号单独录入费率。请使用限定额度的测试 Key。
3. 点击“探测型号”调用该端点的 `/models`，记录响应码、发现的 ID、耗时、请求号和响应哈希。发现的型号仅是端点自报，不能据此认定底层模型身份。
4. 选择一至四个固定任务。单路最多四次、双路最多八次真实调用；两路发送相同提示词、输出上限、温度零的请求。无自动重试，故障同样记录。
5. 每次上游尝试保存独立流水编号、端点、任务、提示词/结果哈希、有限结果样本、响应码、上游请求号、请求与响应的型号、上游原始计数字段、输入/缓存/输出 Token、总 Token、耗时、估算采购成本、格式检查、任务分数及错误码。评分只检查四个确定性任务，不代表模型完整能力或官方型号真实性。
6. “逐笔交易”显示异常原因，可下载最近最多 1000 笔 CSV（含本台流水、上游请求号、UTC 时间、Key、型号、原始缓存计数与估算成本）。没有上游请求号时，不能声称逐笔已与供应商对上。
7. “计费核对”只核对本工具产生的**探测请求**。必须填写可回查的上游账单编号或导出文件编号，且选择同一端点、同一时段的金额；空时段、存在无法估价交易或与既有核对时段重叠时拒绝记录。共享采购账户的总账单不能直接当成探测账单。差额即使为零也只是人工填报的金额相同，仍需复核原始账单范围和请求号。

### 当前测试材料与判定

| 项目 | 发给两路 API 的同一题目 | 通过条件 |
| --- | --- | --- |
| 事实与计算 | 只输出 17 × 23 的整数结果 | 严格等于 `391` |
| 结构化 JSON | 输出 `result=42`、`ok=true` 的 JSON，不用 Markdown | 能解析且字段类型与值正确 |
| 中文表达 | 把 “Hello, world!” 翻成简体中文 | 包含“你好”和“世界” |
| 上下文理解 | 已知甲城代号蓝星、乙城代号红星，问乙城代号 | 严格等于“红星” |

每题请求 `temperature=0`、独立输出上限；题目通过得 100，否则得 0。HTTP/协议检查、用量自洽检查与任务分数分别保存，不能把四题均分称作模型质量总分。此版本尚无长上下文、工具调用、流式首字延迟、并发压测或持续定时拨测；增加这些测试前应先明确授权、成本上限、标准数据集和可复核的评分规则。

## 成本算法

`估算采购成本 = (输入 Token - 缓存命中 Token) × 非缓存输入价 / 1,000,000 + 缓存命中 Token × 缓存输入价 / 1,000,000 + 输出 Token × 输出价 / 1,000,000`。

费率和 Token 先按整数运算，再以 12 位小数存库。缺少费率、缺少需要的缓存计数、总 Token 与输入加输出不一致时，该笔标为无法估价，不会默认为零。费率随端点记录固定；调整价格时新建端点，旧交易保留原口径。

响应缺少型号、型号与请求不符，或缓存命中加未命中不等于输入 Token 时，验收台保留原始计数字段并标记异常，不把该笔算作可核对响应或可确认的估算成本。HTTP 200 只说明请求到达，不能单独代表验收通过。若供应商不回报缓存计数，而合同区分缓存价与非缓存价，该笔费用保持待核。页面中的采购成本始终是**估算**，上游账单需另行核对。

## 尚未接入的账务边界

客户真实调用网关和客户扣费尚未开放。验收台**不会**把探测流水冒充客户用量，也不能宣称已核对客户账单与供应商账单。正式调用链路需要先产生客户请求关联 ID，再分别记录客户请求、每次上游尝试（包括重试）、供应商返回用量、按客户价结算金额和账本扣费，最后按模型、请求号和时段对账。若上游不返回逐笔请求号或用量，应单独标记为不可核对。

供应商自报的型号与官方对照端点得到不同结果、Token 或延迟，只能触发人工复核。对外声称“官方同款”仍需要合同授权、版本证据和更大样本的评测。
