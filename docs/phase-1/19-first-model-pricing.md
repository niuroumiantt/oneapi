DeepSeek [官方型号与价格](https://api-docs.deepseek.com/quick_start/pricing/)在本次核对时显示，`deepseek-flash` 对应 DeepSeek-V4.1-Flash-1017。官方每百万 Token 的美元采购参考价如下：

| 计量 | 非高峰 | 高峰 |
| --- | ---: | ---: |
| 输入，缓存命中 | $0.003 | $0.006 |
| 输入，缓存未命中 | $0.15 | $0.30 |
| 输出 | $0.60 | $1.20 |

官方按工作日 UTC 时段区分高峰，并可能调整价格。我们的人民币客户价不应直接照搬美元成本，也不能假设缓存必定命中；定价前须取得实际结算币种、汇率与服务费、付款通道费率和退款规则。首版建议客户只看到清楚的输入价、输出价和适用范围，平台内部用高峰且缓存未命中场景验证毛利下限；缓存节省可以留作缓冲。若提供视觉、搜索或其他按次收费能力，必须另列价格，不能塞入文本 Token 单价。

2. 录入人民币输入/输出价格草稿，保留依据链接与版本。
3. 商品由独立人员复核；另一位具备财务或平台管理权限的人员复核最新价格，不能审批自己设计的价格。后台把这一步记为**内部价格已批准**。
