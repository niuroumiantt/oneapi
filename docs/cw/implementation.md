# CW 推广合作伙伴实施规则

2026-11-19。已确认：实付 10% 形成预计税前佣金，实用 10% 解锁；自然月结束并与客户完成结算后，财务确认释放可提现金额。首个客户优惠为官网原价 50%，每个码可申请不同优惠，商务审核后生效。每名 CW 最多 50 个推广码；不删除历史码或把码转给别人。

## 对象与归属

普通客户登录账号可申请 CW，不授予员工或企业权限。个人永久 CW 编号用于身份和邀请；活动推广码另行分配。邀请 A→B 仅记录来源，B 独立签约；B 的码产生 B 的直接佣金，不自动给 A 或其他祖先返点。上下线业绩抽佣没有启用。

推广码是公开标识，不是身份凭证。数据库唯一约束配合随机生成与事务锁；最多 50 个含待审、停用、拒绝历史记录。首版采用 8 位易读英文、不区分大小写；中文别名暂未接入。

每笔支付单保存 CW、码、客户折扣和 10% 佣金规则快照。CW 客户输入实付 100 元，五折时到账 200 元官价额度；普通充值和旧促销码继续按原语义处理。客户确认页必须展示码、实付和官价额度。确认后创建订单会同时核对实付和到账额度，活动变化时要求重新确认。订单创建后修改码规则不影响该单；不将历史无归属订单补计佣。

## 账本

支付验签入账与预计佣金同事务，订单唯一。已消费实付由 credit_packs / credit_consumptions 的 FIFO 分配决定，不从当前余额倒算。累计到分再向下取整佣金，避免小额多次调用产生舍入超付。

预计总佣金包含已解锁部分；未消费退款取消未解锁佣金。现有退款接口退整个额度包的未消费部分，已消费服务退费或拒付须先新增独立佣金负向调整流程，不得绕过本账本改金额。

CW 只看到自己各码的支付、实际使用和退款事件、时间、匿名成交编号、金额和佣金变化。不会收到客户姓名、邮箱、付款渠道完整订单号、API Key 或调用内容。管理员可按权限查看付款归属和客户计费账户。

月结确认是 account_id + YYYY-MM 的独立记录：月末已过、没有该月待结算调用、支付账单匹配、没有待处理退款。财务录入客户结算凭证后释放对应使用事件的佣金。不是充值月底自动可提。使用事件保留调用发生时间，按北京时间归属消费月份；跨月确认的调用仍归原消费月份。存在未结算调用时禁止提前确认该客户月份。

提现锁定 CW 行并原子占用可提事件；重复请求幂等、并发不超额。退回/失败释放占用但保留原分配记录。财务审核填写实际代扣税额，核验银行最终结果后才标记已付；银行结果不明保持待确认，禁止盲目重付。首版人工银行付款，无自动打款接口。

## 合同、资料与上线条件

协议草案在 agreement-draft.md 与网页呈现，不能当作已生效合同。真实签约服务商未指定。支持管理员登记经核实的双方签署凭证、文件 SHA-256、实名核验参考号和有效期；没有有效签署记录，不激活合作及促销码。

联系方式和银行卡用现有 AES-GCM vault（独立 CW 派生上下文）加密。对外只显示卡尾号；财务查看明文记录原因及审计事件。换卡后旧核验失效，处理中提现禁止换卡。服务商实名核验保存参考号，不在 Git/日志收集证件照片。

CW_ENABLED 默认 false，只有明确启用的环境开放申请。正式合同定稿和签约接入尚未完成，禁止把测试数据、测试签约凭证当作真实上线证据。
