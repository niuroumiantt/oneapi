## 五模块现状

| 模块 | 已具备 | 尚不能作为正式业务使用的部分 |
| --- | --- | --- |
| 身份与权限 | 个人邮箱注册、验证、登录；企业代表创建空间、登记员工、调整角色与状态；内部员工 OIDC 与岗位 | 企业成员真实模型授权和额度依赖正式商品与调用账本 |
| 供应商与验证 | 供应商档案、供给型号、资料核验、测试与验收报告、阻断状态、内部审计 | 商业转售授权、合同、采购账单、生产密钥保管和持续探测尚未验收 |
| 模型广场与商品 | 品牌/型号预览、内部商品资料、价格草稿、独立复核流程 | 没有已批准的客户人民币售价和可售型号；广场卡片不是购买入口 |
| 付费与用量 | 个人/企业独立只读资金账户，企业首屏资金展示；隔离模拟订单、付款、额度、接入、调用与记录 | 微信/支付宝商户未开通，不能生成真实收款码或入账；正式平台 Key 与模型调用关闭 |
| 促销 | 内部活动、折扣、佣金、优惠预算草稿 | 不能发放、兑换或计佣；须基于已批准售价和真实结算事件 |

## 继续实施的最短路径

1. 取得首个供应型号的转售/商用授权、准确模型 ID、计费和数据处理材料，完成供给与技术验收。用户已说明智子芯元主体，合同资料稍后提供；DeepSeek 个人测试 Key 只证明本机一次测试调用成功，不等于转售授权。
2. 批准首个模型的客户价，分别给出输入、输出 `¥ / 1M Token`，再发布可售商品。没有价格时不开放订单或按 Token 扣费。
3. 开通微信或支付宝商户后，按空间与付款人建立充值订单；先验签、查单、幂等入账和对账，再展示真实扫码付款。最低充值 ¥5。退款手续费政策须单独核验，当前不执行 15% 扣费。
4. 资金和商品都可用后，发行仅展示一次的平台 Key，限定空间/型号，接上游调用、计量、扣费与用量明细，再开客户入口。
5. 最后将促销绑定已发布价格和真实付款/用量事件，加入预算上限、退款冲回与佣金对账。

隔离的 `#demo/personal` 与 `#demo/organization/:id` 已可把选模型、模拟充值、模拟接入和用量走完，但所有金额、Key、调用与退款均为演示，不能视为真实上线。生产状态继续保持 `business_ready=false`、`payments_enabled=false`、`inference_enabled=false`。
