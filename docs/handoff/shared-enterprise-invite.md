# 企业共享邀请交接

2026-11-08，源码提交 `618dbae8e919f6ee92ca199460d5467f908759f0` 已推送并部署到 `oneapi.glocalstorage.cn`。线上 `/release.json` 和 `/api/status` 均返回该 SHA；API 与数据库容器健康，旧 `api.glocalstorage.cn` 返回 200。

## 本阶段

- 企业代表人创建有效期七天的共享加入链接，既可发给一人，也可发给多人；链接可撤销。
- 收到链接的人用任意邮箱注册或登录，验证邮箱后提交加入申请。企业代表人逐条批准或拒绝。
- 批准后身份为企业成员，初始预算为零，未授权模型；费用与个人空间隔离。
- 删除逐邮箱邀请 API、前端入口以及未被使用的旧企业演示脚本和样式。保留生产旧邀请表与数据，不执行破坏性迁移。
- 集成测试 18/18 通过；静态包构建及源码 SHA 校验通过。部署前备份专用数据库与配置。

## 能力边界与下一步

`/api/status` 当前 `payments_enabled=false`、`inference_enabled=false`、`business_ready=false`。身份与企业申请审批是真实功能；供应资料、商品定价和活动为内部草稿；充值、API Key、调用、用量、退款是隔离演示。下一条小而美主线：先接真实供应与商品价格，再接商户支付和独立资金账本，然后实现客户平台 Key、一次真实调用和余额用量展示。详细状态见 `docs/phase-1/18-product-flow-implementation.md`。
