# 个人自助退款入口交接

2026-11-24 · m5

- 个人概览的「去退款」直达 `#billing/personal/refunds`。退款页先显示可自助退的合计金额，再按充值列出时间、原支付方式、可退实付款和会收回的赠送额度。逐笔确认，按原支付渠道退款，无手续费。
- 「资金记录」仍保留充值记录和资金流水，各有标题与独立间距，个人账单可从该页进入退款。退款页显示待处理、处理中和已退款状态，并提供刷新。
- 提交前再次核对客户确认的可退金额。金额变化时返回冲突提示，客户刷新后重新确认。已开票和用量在途限制沿用现有退款规则。
- 已使用截图金额构造本地模拟数据，验证桌面、手机、短屏、返回导航和退款状态。支付宝、微信及发票锁定三项 PostgreSQL 集成测试通过。验收未在生产账户发起实际退款。线上前后端版本分别以 `/release.json` 和 `/api/status` 为准。
- 文件入口为 `web/identity.js`、`web/identity.css`、`server/src/billing.mjs`、`server/src/payments.mjs`。发布按 [上海部署说明](../deployment/shanghai.md)。
