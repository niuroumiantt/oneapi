# CW 合作伙伴交接（2026-11-19，m5）

## 用户确认规则
- 实付 10% 预计、实用 10% 解锁；自然月结束且公司与客户结算确认后才能提现。首个报价五折，支持不同码申请不同折扣，每名 CW 最多 50 个码（含历史码）。
- 独立客户身份申请 CW，无员工权限；邀请码只记录来源，不启用层级业绩返佣。8 位英文永久身份编号与活动码分开，大小写不敏感。
- CW 看本人的每码实付、实用、时间、匿名成交、预计/解锁/可提现；公司有专用管理入口和实名订单、合同、月结、提现审核。

## 实现
- `server/src/cw-partners.mjs` 路由与审批，`cw-ledger.mjs` 原子计佣；迁移 `072_cw_partners.sql`。
- 支付单保存归属/优惠快照；现金输入必须同时确认到账额度，优惠变更要求重确认。重复支付、计费与提现均不能重复计佣/超提。
- 月结按调用发生月份（北京时间），待计费调用/未对账支付/待退款阻止月结。银行资料加密、版本核验，查看明文审计；人工银行付款须登记最终结果。
- `web/cw.html` 客户门户，`web/cw.html?staff=1` 公司管理。头像菜单及商务后台「产品 → CW 合作伙伴」入口。推广链接/注册邮件保留活动码；CW 注册保留邀请来源。
- `CW_ENABLED` 默认 false；生产开放申请需明确设 true。每个真实 CW 仍须审核签约凭证、身份、活动码、收款卡，才能经营/提现。
