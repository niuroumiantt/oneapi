# 充值 付费 Key 与退款进度交接

2026-11-25 · m5

- 充值按服务端报价和订单展示实付、赠送额度、到账额度。付款确认、待付款、成功回执与充值记录使用同一计算口径，历史订单金额取购买时记录。
- 付费 Key 可多选或全选当前开放型号。消费上限留空时，采用预览的账户未分配额度。创建时锁定账户重新计算，预览金额变更后要求用户重新确认。全选只给本次选中的已开放型号授权。
- 退款页按订单显示提交、财务等待或渠道处理、原路退回或失败。时间统一为北京时间；迁移前没有记录的渠道处理起始时间显示「时间未记录」。渠道确认时间用于页面结果，不推断银行入账时间。
- 临时 PostgreSQL 的四项专项通过，包括折扣入账、并发 Key、退款处理和失败、发票限制。Chrome 用模拟数据覆盖结算金额、手机多选和退款时间。全量回归 183 项通过，8 项失败与既有基线一致。
- 新增加法迁移 `082_refund_progress.sql`。发布与版本核对按 [上海发布说明](../deployment/shanghai.md) 执行。测试未使用生产付款或退款。
