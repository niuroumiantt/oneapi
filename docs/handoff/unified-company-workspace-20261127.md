# 统一公司员工工作台交接（2026-11-27，m5）

## 目标

个人账户使用个人工作台，VIP 管理嵌在个人工作台。公司员工使用同一个员工工作台查看自己的公司 API 额度、模型、密钥和用量，并按岗位跟进客户与 VIP。老板使用现有老板工作台管理商务、技术、财务、人员和供应链。

## 实现

- 用户身份响应对已配置公司的有效组织关系标出员工或老板入口。公司旧组织书签按栏目跳到新工作台；其他企业关系和个人历史业务数据保留。
- 删除旧模型目录双栏、拖动、过滤、接入面板和两套重复的公司 Key 创建表单及专用样式。统一员工的「我的 API」沿用个人 API 模板和公司额度接口。
- 公司员工工作台继续通过现有公司 SSO 和岗位授权。员工客户归属、VIP 跟进范围及老板接口的后端权限保持现有校验。
- 生产已只读核对 Larry 是有效 Glocal Team 成员。该邮箱尚未有内部员工岗位登记，早期成员记录没有新版邀请审批流水。自动审批拒绝了代码自动赋予运营角色，因此发布前要通过现有公司身份登录和老板授权完成真实账号验收。

## 验收与入口

- 34 项本地测试通过，包括旧路由映射、公司邀请审批与移除、公司额度守恒、普通员工与老板权限隔离、个人页面及共享 Key 界面。
