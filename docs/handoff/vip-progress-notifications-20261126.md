# VIP 申请进度与通知交接（2026-11-26，m5）

## 目标与规则
- 申请人提交后看到流程、当前阶段、负责员工及下一步；员工与管理员收到邮件和站内提醒。保留现有面试、累计有效实付 ¥100、人工核验开通及特殊审批规则。
- 通知按现有客户归属隔离：负责员工和有效管理员可见；未分配客户由管理员处理。其他员工不获得客户资料。申请人使用已绑定邮箱接收阶段反馈；纯手机账号在申请页查看。

## 实现
- 客户进度每 15 秒自动更新。已达标隐藏再次付款入口；申请未通过/暂停可展示明确标记为客户可见的反馈，不泄露原有内部审批备注。
- 后台先显示当前步骤与主要操作。移除 VIP 页重复商务导航，内嵌页面自适应高度，使用外层页面滚动；特殊审批与合同财务资料渐进展开。
- 迁移 089：持久通知事件及员工已读表，申请、面试、发码、开通、分配、特批、充值事务触发通知。历史未完成申请补站内提醒，不补发历史邮件。
- 新事件由原 3 秒邮件工作循环批量转入 mail_outbox；入队与完成标记同事务，失败退避一分钟，SMTP 未配置时保留事件。SMTP 投递继续沿用原 outbox 重试。充值邮件保留已有支付通知渠道。
- 全站顶栏通知每 15 秒检查一次；点击直达客户档案，已读与处理完成分开。权限变更按当前归属生效。
- 静态构建加入通知脚本与内容哈希，site-header 引用实际产物名。
