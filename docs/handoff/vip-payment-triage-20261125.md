# VIP 原单核验与到账通知（2026-11-25，m5）

商务后台进入「VIP 客户跟进」。已知商户订单号时，用「按订单查客户」定位原单。客户档案显示个人账户近 100 笔在线充值，下单与入账时间、普通充值或专属 VIP 付款码、实付、到账额度、退款金额和入账状态。较早的原单可以按完整订单号查询并置顶。

销售可以查看名下客户与原单。管理员也可查询尚未关联 VIP 档案的订单，确认款项落在个人还是企业账户。订单类型以付款时的折扣快照为准。充值展示和反查不会改原订单、扣款或改变申请资格。

新入账的两类 VIP 客户个人在线充值会进入邮件队列，收件人为在职负责销售和 `sales@glocalstorage.com`。两者是同一邮箱时只排一封，重复支付通知或查单也只排一次。邮件队列故障时款项仍照常入账，支付日志以 `vip_recharge_notice_failed` 记录异常。历史订单继续按原单核验，系统不补发旧邮件。

测试使用隔离数据库、模拟支付回执和邮件队列。上线后用已有商户订单号验收，停在只读结果。
