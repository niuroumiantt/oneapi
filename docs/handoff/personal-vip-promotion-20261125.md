# 个人账户与 VIP 宣传页交接（2026-11-25，m5）

## 目标

提供两张可单独分享的中文宣传页，并精简从个人账户申请 VIP 的界面。

## 页面与申请流程

- `/promotion/personal-start.html` 介绍手机号或邮箱注册、验证、充值、付费 Key 和首次 API 调用。接入地址为 `https://semifly.cn/v1`。
- `/promotion/vip-start.html` 介绍个人账户登录、使用员工邀请码申请、电话面试领取打折码、单笔实付满 ¥100、销售核验与开通。两张宣传页互相可达，VIP 指南连接已有申请页 `/promotion/vip.html`。截图用本地模拟数据。
- 申请表显示姓名、联系方式、员工邀请码、资料同意和提交。选填的邀请人 VIP 编号默认折叠，有邀请链接时自动带入。页面由浏览器正常滚动。推广与收益菜单在正式开通后显示。
- 申请中和面试后的「刷新状态」重新查询服务端。游客分别获得登录和注册入口，继续使用现有 `cw_join` 回跳。
- `scripts/build_static.py` 将两页、样式及截图打入发布包。中国站注入备案链接，样式及截图使用内容哈希。

## 流程核查待处理

1. 销售开通条件目前按原始支付额 `amount_fen` 核验，退款只累加 `refunded_fen`，订单仍为已支付。需要明确退款后按哪种金额核验，以及正式开通后退款是否影响资格。
2. 面试通过后的充值入口未预填 VIP 客户打折码。指南标明「有促销码？」的填写入口和付款确认项。
3. 邮箱注册成功后的验证提示与已有账户的帮助混用。可单独确认发送状态，并提示验证后会回到哪里。

## 验证与发布入口

以当前隔离工作树为准。Chrome 本地用模拟接口验证两张宣传页的 320、390、768、1024 和 1440 像素布局，以及 VIP 访客、申请、填选填编号、提交、待面试、刷新后面试通过、正式开通与员工视图。中国站发布包解包后重复通过浏览器检查。两域发布包都验证了入口、静态资源与分享图片，备案链接仅写入中国站。文案检查通过，营销模板的整屏、栅格及动效检查仍有差异，页面采用紧凑的自然滚动版式。线上仅核对公开入口、认证方式及已部署版本。本次发布以 `docs/deployment/shanghai.md` 为入口。
