## 欢迎页再设计

用户否定之前两张大入口卡片，明确要求年轻、科技、跳动、欢快。当前 `#login` 改为品牌欢迎页：左侧大字与原创轨道花形，右侧个人/企业切换和一个主按钮。手机竖向排列，动效可暂停并适配减少动态偏好。模型广场仍是首页，真实登录未启用。当前规范见 design/spectrum/brand-and-icons.md；不要恢复旧双卡片方案。

## 宇宙方案预览

用户已认可新版欢迎页，要求全站同等设计感，并希望先看宽阔宇宙、仙女星系、太阳方向。新增 #universe 独立动态视觉预览，保留 #login 已认可方案以便比较；暂不把全站改成深色。视觉由本地 Canvas 和 CSS 实时绘制，沿用现有客户选择和员工入口，动效可暂停。后续应先延续用户对宇宙方案的反馈，再扩展到全站。

## 宇宙版明显公转

用户认为原宇宙版看不出运动。现已替换固定的装饰行星为完整可见公转系统：太阳、八颗行星、冥王星、月球。默认演示周期 12–64 秒，月球 4 秒；速度可选 0.5×/1×/2×/4×，暂停与恢复实测通过。轨道大小与速度是视觉示意。减少动态偏好默认暂停，用户可主动播放。#universe 路由保持不变，原 #login 方案保留。

## 模型广场设计统一

用户认可宇宙方向，要求 0.1×/0.2× 慢速选择并重做模型广场。已新增两档，默认 0.2×。#market 已改为宇宙首屏、暖橙操作、明亮模型目录、四款淡彩行星插画、用途快捷筛选和工具接入区域；保持既有筛选与演示配置能力，员工入口低调。与 #universe 品牌统一，真实业务状态仍未开放。
