# 客户 API 对比台 — 2026-11-17

## 范围与入口

用户批准按已确认原型接入真实 API、放入本站并完成测试。新增 `/compare.html`，个人与企业工作台侧栏均有「API 对比」。左侧按登录身份自动列出有已付款、未退款剩余额度的个人或企业产品及当前可调用模型，无需填写平台 Key；右侧支持 DeepSeek、GLM、Kimi、MiniMax 官方预设及 HTTPS 公网 OpenAI Chat Completions 兼容地址。模型可读取或手填，名称不一致提醒但不阻止运行。

共同任务、系统提示、参数及附件形成一份请求快照，平台参数规范化后仅更换模型 ID 分别调用。左侧经过原有 `/v1` 鉴权、余额、限流、隔离及计费链路；不修改既有模型状态，FlashX 输出成本隔离仍有效。右侧为客户选定接口，不自动换模型、降级或重试产生额外费用。

## 实现约束

- API：`GET /api/compare/config`；`POST models / attachment / run`。登录、邮箱验证、Origin 校验、已付费资格与账户权限检查。全部对比 API 均要求有效已购额度。
- 客户自带密钥只在当前页面内存和本次服务端请求中使用，不写浏览器存储、报告、数据库或日志。平台侧每次生成限定账户和模型的内部临时凭证，数据库只存哈希；5 分钟过期，并在完成、失败或取消后撤销，不占客户常规 Key 配额。报告会含任务、文档文字、回答，导出前提示隐私。
- DNS 检查并固定公网解析结果；禁止内网、保留地址、重定向、非 HTTPS/443，保留 TLS 验证。官方地址固定。
- 同用户最多 1 个活动任务、服务端最多 4 个；180 秒超时，最大输出 8192；已发生上游费用无法靠停止读取撤销。
- TXT/MD/CSV/JSON、文字 PDF/DOCX、PNG/JPEG/WebP；5 个文件、单个 4 MB、请求总计 8 MB、文字合计 12 万字符。PDF 最多 100 页、DOCX 解压上限 2 MB；解析线程最多 2 个，单个 96 MB old heap、15 秒。扫描 PDF 无 OCR，文档图片/版式不发送，运行前可预览。
- 缺失 usage 显示未提供；缓存/推理为子项，不能重复相加。速度采用输出 Token / 总耗时，明确端到端范围。非流式、截断或失败不输出速度优劣结论。同名/相似输出不是模型身份证明。
- 图片需要平台模型有 image 输入能力，客户确认参照模型支持；外部工具调用不执行。

## 真实接口抽测

每次最大输出 128 Token，使用既有验收凭据，密钥未导出。

| 接口 | 结果 | 接口报告用量 |
| --- | --- | --- |
| DeepSeek 官方 | HTTP 200，流式完成，回答 OK | 输入 13，输出 1，总 14 |
| GLM 官方 | 关闭思考返回明确 400；按要求 low 模式重测 HTTP 200，回答 OK | 输入 22，输出 17，其中推理 14，总 39 |
| KerAPI 兼容接口 | HTTP 200，流式完成，回答 OK | 输入 13，输出 1，总 14 |

以上只是连通性和协议验证，不能当作速度基准或模型身份证明。

发布、回退等运维细节保留在本地记录，不写入公开仓库。未清理用户资料或其他工作树。

## 已付费用户与临时 Key 提醒修订

- 当前销售的是通用 API 额度包，因此产品下拉按个人/企业已购额度账户展示，模型下拉展示该付费目录当前可调用模型；不虚构按模型购买关系。企业沿用 owner/admin/billing 权限，普通或停用成员不可支出企业额度。
- 未付款、仅有赠送或演示余额、已退款或已用完的额度包不授予对比资格；所有入口在服务端拦截。账户余额仍由原有网关预留和结算控制。
- 大黄色提醒：使用专门的临时测试 Key，不保存、不复用，结束后立即到官方/第三方平台撤销。清除输入框不会使供应商 Key 失效。页面提供清除 Key 按钮，刷新及离页清除输入。
- 新增真实数据库验证覆盖自动产品列表、无平台 Key 对比、一次调用一次结算、内部凭证撤销/过期、常规 Key 列表隔离、伪造账户/模型拒绝、免费及退款额度拒绝、企业权限变更。
- 本地浏览器已验证自动选择产品、双侧流式完成、账本扣费和清除 Key；390px 手机无横向溢出，桌面黄色提醒醒目，无浏览器控制台错误。测试上游使用合成响应，不作为真实模型性能结论。
