# 客户 API 对比台 — 2026-11-17

## 范围与入口

用户批准按已确认原型接入真实 API、放入本站并完成测试。新增 `/compare.html`，个人与企业工作台侧栏均有「API 对比」。左侧使用当前登录用户自己的平台 Key；右侧支持 DeepSeek、GLM、Kimi、MiniMax 官方预设及 HTTPS 公网 OpenAI Chat Completions 兼容地址。模型可读取或手填，名称不一致提醒但不阻止运行。

共同任务、系统提示、参数及附件形成一份请求快照，平台参数规范化后仅更换模型 ID 分别调用。左侧经过原有 `/v1` 鉴权、余额、限流、隔离及计费链路；不修改既有模型状态，FlashX 输出成本隔离仍有效。右侧为客户选定接口，不自动换模型、降级或重试产生额外费用。

## 实现约束

- API：`GET /api/compare/config`；`POST models / attachment / run`。登录、邮箱验证、Origin 校验、Key 归属检查。
- 密钥只在当前页面内存和本次服务端请求中使用，不写浏览器存储、报告、对比数据库或日志。报告会含任务、文档文字、回答，导出前提示隐私。
- DNS 检查并固定公网解析结果；禁止内网、保留地址、重定向、非 HTTPS/443，保留 TLS 验证。官方地址固定。
- 同用户最多 1 个活动任务、服务端最多 4 个；180 秒超时，最大输出 8192；已发生上游费用无法靠停止读取撤销。
- TXT/MD/CSV/JSON、文字 PDF/DOCX、PNG/JPEG/WebP；5 个文件、单个 4 MB、请求总计 8 MB、文字合计 12 万字符。PDF 最多 100 页、DOCX 解压上限 2 MB；解析线程最多 2 个，单个 96 MB old heap、15 秒。扫描 PDF 无 OCR，文档图片/版式不发送，运行前可预览。
- 缺失 usage 显示未提供；缓存/推理为子项，不能重复相加。速度采用输出 Token / 总耗时，明确端到端范围。非流式、截断或失败不输出速度优劣结论。同名/相似输出不是模型身份证明。
- 图片需要平台模型有 image 输入能力，客户确认参照模型支持；外部工具调用不执行。

## 已完成验证

- 独立本地 PostgreSQL 测试库，120 项回归全部通过（0 失败、0 跳过）。包含真实 Express + 登录 + 平台网关 + PostgreSQL 账本结算；上游为可控 fixture，不冒充真实模型评测。
- 专项覆盖 SSRF/混合 DNS、错误脱敏、SSE 分片 UTF-8/CRLF/晚到 usage、单侧失败、截断、超时、并发、跨用户 Key、Origin、20 KB 共同输入、PDF/DOCX/压缩炸弹、输出成本隔离。
- 浏览器验收：读取模型、同时输出、平台账本金额、第三方地址、附件上传提取、复测命令、中止；390 px 手机无横向溢出，桌面视觉检查、控制台无错误。
- `node --check`、`git diff --check` 与界面检测通过。
