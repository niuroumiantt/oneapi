# 单屏页面与模型档案 · 2026-11-27

## 用户要求
全站采用一屏高宽布局，包括员工和管理员后台。长内容通过栏目、章节或分页访问；切换模型介绍时周围区域不能移动。模型广场暂只展示 DeepSeek Flash、GLM-5.3、GLM-5.3-Flash，补充参数、权重体积、历史、场景和官方计价。

## 实现
- 前序提交 `08e4fed` 提供三模型广场和公开官价快照接口。本轮固定模型选择栏、介绍区、价格区，新增模型档案与版本历史。小屏将价格移入介绍栏目。
- `web/model-background.js` 保存官方模型卡和固定仓库修订来源。权重大小为 Safetensors 文件字节合计的十进制 GB，不是显存需求。DeepSeek 的主干、Engram、激活量和仓库张量统计分别说明；GLM-5.3 未证实的激活参数与训练量不估填。
- `screen-pages.js/css` 为长内容提供区域内翻页与宽表字段分组，边界保留重叠内容，导航和外部布局固定。保留原表单节点、事件和业务权限。弹窗分页控件保留在 dialog 顶层内。后台小屏使用栏目选择框。
- 文档按 H2 分章节，多语言代码用独立标签；Skills 分精选、目录、说明，目录每页 3 项（窄屏 1 项），详情分栏目，完整内容在详情中。实测报告分概览及五个栏目，打印恢复完整内容。
- 独立推广说明、合作条款、优惠码明细、API 对比与 VIP 页纳入固定视口。受保护后台通过 workspace-bridge 加载共享布局；静态包保留 screen-pages 根路径别名。
