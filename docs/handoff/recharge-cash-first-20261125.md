# 充值按实付金额交接（2026-11-25，m5）

个人和企业账单的在线充值表单统一输入实付金额。输入 ¥100 时，5 折活动报价为实付 ¥100、赠送额度 ¥100、到账额度 ¥200。普通促销码、VIP 付款码和无促销码走同一入口。旧面额 API 客户端仍可继续提交面额。

站内确认页展示三笔金额和支付方式。只有用户确认后才会创建支付订单。服务端保存实付请求及优惠快照，并再次核对实付和到账额度。付款结果、充值记录沿用同一三额展示。

本地 PostgreSQL 验证了普通 5 折优惠、订单幂等、报价变化拒绝、实付和赠送入账。Chrome 使用模拟账户观察到确认页，未发出付款请求。发布及验证入口见 `docs/deployment/shanghai.md`。
