# VIP 推广码免逐码审核

2026-11-25 · m5

- 正式 VIP 完成合同与实名核验后可直接生成推广码，符合条件的存量待处理码随资格生效。客户付款码、首充门槛、返佣公式沿用当前线上规则。
- 管理员可从 VIP 客户档案为单个正式 VIP 开通或撤回 7 天推广试用。操作及原因记入审计。生产试用对象为尾号 1166 的 JYYXVGXJ。以真实合同和实名凭证登记签约。
- 独立工作树基于生产版本 8bf3dcc。隔离 PostgreSQL 通过 15 项集成测试，验证旧码生效、连续发码、报价、试用到期及撤回和返佣快照。未产生真实付款。
- 发布后先核对前后端版本，确认 JYYXVGXJ 档案，开通试用并确认已有合格码可报价。与法大大的签约接入独立推进。
