# VIP 工作台 · 2026-11-26

## 范围

用户确认白板建议后，更新个人工作台中的 VIP 申请与管理界面。沿用个人页面的白底、紧凑分栏和单屏分页。没有修改商务后台和财务接口。

- 未申请：计划介绍、申请流程、合作规则、我的申请。
- 已申请：默认申请进度，突出下一步、负责员工、累计有效实付与差额；申请资料独立查看。
- 正式 VIP：单层五标签「概览 / 推广码 / 推广明细 / 佣金与提现 / 合作资料」。合同、银行卡、伙伴邀请属于资料子页，不重复堆两层导航。
- 侧栏位于个人设置下方，保留手绘圈；按已知状态显示去申请 VIP、VIP 申请进度、VIP 工作台。正式 VIP 可用原有 me.user.vip 判定；申请状态从当前同源 VIP iframe 同步，不新增阻塞请求，按当前用户隔离。
- 概览区分客户实付/实用与佣金，预计、已解锁、可提现不相加。充值余额仍由个人账单页管理。
- 推广码生成继续使用合同核验或有效试用资格，后端生成权限不变。推广明细保留匿名交易编号，加入加载、空态、重试及过期响应保护。
- 提现显示缺失条件；提交前用单独一屏核对税前金额和银行卡尾号。尚未审核的税额显示「待核定」，不会显示为零。未实际提交提现。
