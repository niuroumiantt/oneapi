# VIP 原单特批开通（2026-11-25，m5）

「VIP 客户跟进 → 客户档案 → 原单特批开通」可按商户订单号和申请原因提交。通过订单反查进入档案时，申请表预填原单号。负责销售可提交与查看名下客户，实际开通由在职平台管理员填写审批原因后批准。待审项可在 VIP 列表筛选，也会显示在商务后台待办中。

提交和批准均在锁定原单后核对个人账户归属、已支付记录、等额入账流水与退款状态。退款中或已退款的订单不可批准。每笔原单只允许一条特批，退回留痕。批准与 VIP 状态、原单和审批审计在同一事务保存。正常开通继续使用单笔实付 ¥100 的专属付款码条件。

迁移 085 识别具备对应账户、原单和审计的历史运维特批，保留历史审计编号及原因，同步纳入订单唯一约束。历史回填只复制审批凭证，原有账本和 VIP 状态按现状保留。

隔离 PostgreSQL 测试覆盖权限、未入账、订单错配、重复提交、审批前退款、重复审批和历史回填。浏览器使用模拟申请推进审批，不发起付款。上线后在已有历史申请中只读核对回填记录。
