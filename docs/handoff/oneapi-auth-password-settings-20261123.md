# Semifly 登录与密码设置交接（2026-11-23，m5）

- 登录和注册各有一排手机号与邮箱方式选择，彼此用表单底部入口切换。手机号登录默认使用短信，可切到密码登录。邮箱登录保留密码找回和重发验证邮件。
- 账户资料和设置都可进入「登录密码」。手机号账号首次通过绑定手机号的短信验证码设置密码，之后可用当前密码修改，也能在短信登录后重设。邮箱账号继续用当前密码修改。
- 手机号密码使用 Better Auth 的凭据记录。同一个用户 ID 保留已有余额、用量和权限。密码设置或修改后撤销其他登录会话。
- 迁移 075 新增独立的密码短信挑战用途，发送走阿里云 PNVS 重置密码模板 `100003`，计入现有 500 条总额度。验证码用途、手机号和当前账户须匹配。
- 本地用隔离 PostgreSQL 与模拟短信验收首次设置、修改、重设、旧密码失效、其他会话撤销和迁移重跑。真实短信由用户使用自己的账号验收。
- 上海发布以已部署的 `06845db` 为基线。发布脚本先备份，然后执行迁移并更新 API 和静态页面。关闭或回滚新版时，旧版本继续支持手机号短信登录。
- 2026-11-24 经 m4 中转发布 `007c1cb`。备份和迁移完成，API 和数据库健康。公网 API 与页面均报告该版本，手机号及邮箱登录、注册开关和备案页脚已核对。新版密码短信仍待真机验收。
