# 供应商 API 验收台交接（2026-11-09）

## 本阶段完成

- 内部 HTML 入口 `/api/staff/lab/console`，仅已激活的 `platform_admin` / `supply` 员工可访问。页面有总览、凭据和型号、固定任务、官方双路对比、逐笔探测交易、费用抽样核对、近期质量观察七个标签。
- 服务端只允许配置白名单中的 HTTPS API 主机；测试 Key 经 `SUPPLIER_LAB_SECRET` 加密保存，查询接口只返回指纹。支持一枚 Key 关联多个型号，每个型号登记独立采购费率。
- 四项固定任务的每次上游调用独立落库；记录输入/缓存/输出 Token、耗时、请求号、结果摘要、基础评分和按采购费率计算的成本。对照端点使用相同任务和参数。`/models` 发现结果另存证据。
- 费率未知、用量缺失或自相矛盾时不产生估算成本。可录入供应商同一端点、同一时段的探测金额，留存差额。近七天质量观察含成功率、异常和 p95 耗时。
- 本地一次性 PostgreSQL 完整测试 21/21 通过；1440×900 页面渲染检查通过。使用正式 semifly.ai 彩色 Logo。
- 后续修正了线上入口为 `/api/staff/lab/console`（与 Caddy 的 `/api` 反向代理一致），总览直达 API 登记，并在任务页公开每题的提示词与通过条件。三项供应实验单测与脚本语法检查通过；全量测试需要本机允许监听端口并启动隔离 PostgreSQL。
