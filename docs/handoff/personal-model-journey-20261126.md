2026-11-26 · m5 · 本地评审版，未发布。接续个人首页精简；取代此前个人模型页的展开详情方案。

## 产品决定

- 充值增加账户额度，不按单个型号购买。Key 选择一个或多个允许模型，每次请求通过 model 指定型号。
- 新用户：广场了解/比较 → 选择模型 → API 页 → 无额度时充值 → 返回创建 Key → 配置调用。
- 熟悉用户：可直接充值 → API 页创建 Key（默认勾选当前已开放模型，可取消）→ 调用时选型号。
- 已有 Key：匹配允许模型则复用；新型号需在创建 Key 时纳入权限。现有后端不支持修改 Key 的模型集合。
- 充值不会自动提高旧 Key 上限。余额、未分配额度、上限耗尽和 5 把有效 Key 限制分别提示。此轮不改变计费、支付、授权后台。

## 页面改动

- `web/model-explorer.js/css`：公开列表、独立 `#market/<id>` 详情、最多三款规格/价格对比、四项折叠学习内容。六款型号补齐用途、边界、任务示例、能力规格、价格和来源；不用虚构排行榜或速度成绩。
- `server/src/official-models.mjs` → 生成 `web/model-catalog.js`：输出已有结构化能力字段，保持价格与路由不变。平台能力和官方上限分开说明。
- `web/app.js`、`web/index.html`：挂载新广场；未取到线路状态不宣称已接通；个人使用入口带型号转入 API。
- `web/identity.js/css`：模型页只筛选/选型；API 页管理密钥与接入；教程在 API 页折叠。充值保留选择并提供继续配置入口。手机模型/密钥按行纵向阅读。
- 所选型号使用原 model-intent localStorage 键，验证目录 ID、scope、时间及 7 天有效期；覆盖原先遗漏的 0910、FlashX。登录/注册及充值往返保持选择；创建成功后清除。
- 首页已完成的精简继续保留；修复进行中预留额度为小数分时首页 BigInt 转换问题。
