# 阿里云账单核对与费用归属

## 口径与实现
- 读取账户月汇总、资源月汇总、计费项月明细三份原始数据，按产品与币种展示差额，保留高精度及负调整。
- 核查发现资源汇总与计费项存在更新进度差，历史账单还包含 WipeZero 调整。真实账单、资源标识和凭据只留在受保护运行环境，不进入源码。
- OneAPI 成本只累计平台管理员确认的具体资源、产品、计费项、所有者及账期。共享比例必须有依据；默认不分配，不使用容量模型估算比例。保存和修改均审计。
- 新表 cloud_cost_allocations，迁移可重复执行；不会修改原账单、余额或已有凭据。
- 本平台月末预测：月初到前两天的日账单实际，加最近七个完整日按量净费用日均乘剩余天数。包年包月只计已发生金额一次；不预测未来续费。数据不完整时不提供估算。
- 官方预测仍未接入。账户估算与 OneAPI 成本分开；未确认归属时不提供 OneAPI 专属预测。

## 待用户确定
共享资源的分摊依据尚未确认。用户可选择未来实测用量（历史保持未知），或提供固定比例及适用账期；不得代填估计比例。区域聚合 OSS 没有桶级归属证据，不计入 OneAPI。

## 验证
精确小数、负调整、分页失败、过期快照、规则范围隔离、重复保存、管理权限、审计、预测排除重复订阅、页面展示均有自动验证。发布后应确认真实账单各项状态与页面会话；发布版本以线上状态为准。
