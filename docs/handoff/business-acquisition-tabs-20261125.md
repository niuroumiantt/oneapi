# 商务管理分区与员工直营折扣码

2026-11-25 / m5。用户明确要求先上线，本轮从 origin/main a95cd18 建立隔离工作树。

## 已实现

- 商务管理五个固定入口：工作概览、VIP 招募与管理、直营客户与折扣码、VIP 推广与返佣、审批中心。老板可按员工筛选，普通商务员工仅获取自己的客户和码。
- VIP 档案嵌入商务布局；个人申请入口保留在个人侧栏，删除右上角混淆业务身份的合作伙伴入口。
- 直营折扣码：8 个英文字母或 8 个汉字，默认五折立即生效，其他折扣仅平台管理员审批。复制码、链接与下载二维码；有效期必填、最长一年，过期不可恢复或复用，跨码类型防重。
- 直营订单按商户单号查询，实付和到账额度分别显示，不产生 VIP 佣金。新 migration 087_direct_customer_discounts 已登记在 migrate.mjs。
- VIP 客户申请页显示负责销售及已到账记录提醒；正式开通门槛与原单特批规则未修改。合同与实名状态仍真实显示；既有试用权限未伪造签约。
- 法大大接入另一个工作树负责，不包含本次发布。
