# VIP 申请链接交接（2026-11-25，m5）

## 目标

销售从「VIP 邀请码」复制自带邀请码的申请链接。已有会话的客户直接看到表单，访客在登录或完成注册后回到同一个表单。

## 实现与验收

- 链接使用 `/promotion/vip.html?invite_code=...`。申请页预填有效格式的员工邀请码，客户核对资料并主动提交。已有申请的客户打开链接会看到自己的申请进度。
- `web/cw.js` 负责发码入口和申请表。 `web/identity.js` 负责把邀请码带过短信注册、邮箱验证和登录回跳。邀请人的 VIP 编号继续使用独立的 `invite` 参数。
- 本地 Chrome 和独立 PostgreSQL 已验证销售生成邀请码并复制链接、短信注册和邮箱验证回跳、已登录客户打开链接并提交、客户归属发码销售。短信和邮件使用本地测试接收端。VIP 后端集成测试 14 项通过。
