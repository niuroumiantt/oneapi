# Semifly 客户登录交接

- 重复注册会给出登录、找回密码和换邮箱入口。只有提供该邮箱账号的正确密码时，才明确确认该账号已注册。普通访客仍可直接走找回密码，服务端对邮箱是否存在使用同一响应。
- 短信登录接入 PNVS，现有客户先验证当前密码与手机号，再用短信登录同一个账号。限制发送频率、验证次数和有效期。测试包括密码验证、验证码错误、用途隔离、验证码重放和已有账号登录。
- 默认关闭短信入口。待配置阿里云 PNVS 凭据、签名和模板并完成真实短信测试后启用。微信扫码暂处于可行性确认阶段，需要微信开放平台网站应用资料和 `semifly.cn` 的授权回调域。
