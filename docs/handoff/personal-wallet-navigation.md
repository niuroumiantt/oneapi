## 本轮完成

- 公共主导航收敛为“首页 → 模型广场 → 我的空间”；原五模块 landing 仍可通过原链接访问，不再占主导航。`#market` 现在直接展示模型目录。
- 模型卡片明确输入、输出的 `¥ / 1M Token` 单位；客户价尚未批准，保持“待定价”，不把算术示例作为报价。

- 修复个人空间模型意图提示在新版首屏的插入位置。

## 下一步

商户开通前不能实现真实扫码支付；客户价未批准前不能报价或扣费。接下来依 `docs/phase-1/20-recharge-system.md` 做按空间归属的充值订单和付款人记录；商户凭据到位后接验签、查单、幂等入账、对账和原路退款。供应授权及公开售价通过后再开放正式 Key 和调用。模拟体验台与真实资金账本继续隔离。
