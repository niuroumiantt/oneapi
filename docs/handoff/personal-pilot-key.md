# 个人模型目录与受限真实调用

2026-11-10。个人空间的模型目录与右侧接入配置可拖动分栏，宽度仅保存在当前浏览器。DeepSeek 测试通道仅允许 `sales@glocalstorage.com`、`niuroumian@163.com` 两个已验证账号创建测试 Key。每人最多 3 枚有效 Key、两款模型共用每天最多 10 次请求、同时 1 次请求；每枚 Key 固定绑定 `deepseek-flash` 或 `deepseek-v4-pro`，纯文本非流式、最多 4000 输入字符和 256 输出 Token，固定关闭思考模式。Key 只展示一次，数据库只保存 SHA-256 摘要。停用即时生效。

测试调用使用平台服务器保存的 DeepSeek 上游 Key，经 `/v1/chat/completions` 转发。请求正文与回答不入库；逐次保存型号、状态、实际输入/输出/缓存 Token、耗时、上游请求 ID 和按该型号官网高峰价保守估算的上游成本。返回型号必须与请求型号一致。测试不扣客户现金账本，也不代表正式商用开通。其他 `/v1` 路径继续关闭。

个人模型目录的“最近实测”只读取本账号已有的逐笔调用耗时。近 24 小时最近一次调用成功才显示绿色毫秒数；失败、过期和未调用分别显示对应状态。这里是平台到上游的单次响应耗时，不代表长期 SLA。刷新已存数据不发送模型请求，不消耗 Token。

部署顺序：备份 OneAPI 数据库；将上游 Key 保存为只允许容器用户读取的服务器文件，并只读挂载到 API 容器；配置 `PILOT_DEEPSEEK_KEY_FILE` 和 `PILOT_USER_EMAILS`；运行 `020_pilot_inference.sql` 与 `021_pilot_v4_pro.sql` 迁移；发布 API 与前端；只将 `/v1/chat/completions` 转发到 OneAPI API 容器；验证非授权账号不可创建 Key、匿名请求 401、其他 `/v1` 路径 503。不得把上游 Key 放入代码、浏览器、镜像或日志。
