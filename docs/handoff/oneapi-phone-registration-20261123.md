# OneAPI 手机号注册交接（2026-11-23，m5）

Semifly 的注册入口优先展示手机号注册，并提供邮箱注册。中国大陆手机号可直接填写 11 位，也可加 +86。注册验证码验证后，数据库在同一事务中消费验证码并创建账号和手机号绑定，随后创建登录会话。

- 注册复用阿里云 PNVS 登录与注册模板 100001。注册、登录和绑定共享上海 ECS 每 24 小时 500 条的发送上限。注册另设每手机号 24 小时 3 次和每来源 IP 每小时 5 次请求限制。
- 已绑定号码在验证码核验后提示使用短信登录。手机号账号起初无真实邮箱和密码，通过短信登录，个人设置可查看手机号尾号。更换号码和绑定邮箱是后续功能。
- 迁移 074 扩充短信挑战用途。Better Auth 增加 `phoneOnly` 字段，既有用户默认值为 `false`。手机号全号只传给短信服务，数据库保留 HMAC 与尾号。
- 在临时 PostgreSQL 上使用模拟短信验证注册、并发核验、防重放、重复注册、短信登录、共享发送上限和个人账务访问。
- 标准发布使用 `scripts/publish_shanghai.sh`。上海发布脚本先备份，再迁移、更新 API 和静态页面并检查版本。若回滚到不支持手机号注册的旧版本，手机号账号数据会保留，但需要恢复到兼容版本才能继续短信登录。
- 上线后核对 `https://semifly.cn/#register`、`/api/public/auth-methods` 的 `phoneRegistration` 以及前后端版本。真机验证由用户使用自己的新手机号发起。
