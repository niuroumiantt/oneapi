# 全站配色与账户资料

四套配色使用共用样式变量和换肤控件。个人、企业与 VIP 工作台、公共首页、模型广场、文档、Skills、API 对比、指南和独立账单明细沿用同一浏览器偏好。嵌入页通过浏览器存储事件同步。默认使用银灰雾白。先前的个人换肤浏览器偏好继续有效。

个人设置、企业设置和 VIP 资料复用资料行。企业角色、部门管理、登录会话以及 VIP 合同和收款权限仍由各自既有页面和服务处理。配色功能不需要账户同步、数据库字段或权限变动。

打包版已在 Chrome 用演示账户复核首页、模型、文档、Skills、个人、企业设置、VIP 资料、嵌入 VIP 和独立指南。包含 320px 窄屏和深色阅读对比检查。相关界面与导航回归 54 项通过。未操作生产付款、真正的 Key 或签约。
