# VIP 模型消费实付统一 10% 提成（2026-11-27，本地）

## 用户决策
- 每个模型独立促销包；平台设置模型最低售价。当前本地成本 3500 bps（3.5 折），最低售价 5000 bps（5 折）。
- 新模型订单 VIP 提成 = 已消费实付金额 × 10%。赠送不计提，充值到账不提前计提。
- 实付/赠送按购买比例扣减。退款仅退剩余实付、注销对应未用赠送，已消费提成保留。
- 不上线、不推送、不合并。个人工作台布局与主题未调整。

## 实现
- migration 094 保存订单提成口径以及模型采购估算快照；历史订单保留旧价差规则。
- 模型报价校验最低售价与 10% 提成后的采购成本覆盖；成本/规则变更要求重新确认报价。
- 每次消费保存估算采购成本（可含小数分），不是实际采购付款或发票。毛利未扣通道费、税费及运营费。
- 平台管理员 GET/POST /api/staff/cw/model-pack-offers 设置 model_id、min_price_bps、cost_bps。调整新增报价版本并审计；VIP 不可修改底价，客户/VIP 返回中不暴露采购成本。
- 模型实付累计后按分取整计佣，避免小额多次调用漏计；旧订单不被新配置重定价。
- VIP 页面统计明确客户实付、消费实付、已记提成；保留含赠送消费额度说明。
