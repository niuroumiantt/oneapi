# Semifly 登录入口与老板首页交接（2026-11-27，m5）

## 目标

从首页区分个人、VIP、老板和员工的登录入口，老板登录后直接进入业务工作台。公司角色继续以服务端权限为准。

## 已完成

- 首页提供四个入口。个人进入概览，VIP 使用同一套客户凭据进入合作计划，老板和员工通过公司身份中心分别进入老板首页与今日工作。
- 公司认证会保留工作台及子页面。老板客户档案、员工推广码等书签认证后可以回到原页。可主动切换公司账号。
- 老板首页首屏直达普通客户档案、VIP 管理和员工管理。待审批数量读取业务后台，员工和老板可直接从工作台退出。
- 既有员工企业 API 书签继续打开原有 API 工作区。老板账号和普通员工的服务端准入规则沿用现有配置。

## 验证与预览

- 在本地身份中心用示例身份走通四种登录，检查了员工打开老板页时的拒绝提示和工作台退出。
- 用本地实际应用打开员工管理，核对邀请区和额度入口。确认普通客户和 VIP 管理入口的跳转。
- 本地演示使用 `STAFF_PREVIEW_PORT=3336 node scripts/dev/staff-preview.mjs`。老板首页地址为 [老板工作台示例](http://127.0.0.1:3336/?identity=owner#console/owner/home)。
- 测试范围包含 `server/test/identity.test.mjs`、员工归属权限集成测试和登录、个人、员工 API 前端回归。
