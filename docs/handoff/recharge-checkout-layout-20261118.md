# 充值付款界面调整（2026-11-18）

客户 Windows 截图暴露了金额输入太小、付款渠道不明显、未开通微信占据大块空间，以及自定义金额与预设选中状态不一致的问题。

- 个人与企业共用两列充值流程：大号额度输入、常用额度、折叠促销码；支付宝图标、明确付款按钮与三步说明。窄屏自动单列。
- 付款按钮位于支付宝标识下方，在 1280×720 有效视口的首屏内可见；未开通渠道改为一行说明。
- 额度/发票/退款完整说明保留在可展开区域，支付前报价确认与退款告知不变。
- 输入清空不能使用旧金额下单；自定义金额同步预设选中状态，选择预设保留促销码。最低 5 元、最高 50000 元，金额校验、后端支付接口与账户权限不变。
- 工作台增加 Microsoft YaHei UI / Microsoft YaHei 字体回退；修复账单窄屏汇总行被压缩而重叠。
- 支付宝标识来自 Ant Design Icons，MIT 授权与出处补入 THIRD-PARTY-LICENSES.txt。

验收使用真实前端及隔离合成账户：1440、1536、1280、1024、390 宽度无整页横向溢出；1280×720 与 1024×768 付款按钮在首屏可见；3 元与空输入被阻止，50 元预设与促销码保留正确。原支付入口/渠道状态 7 项测试通过，JS 语法及 diff 检查通过。宿主机为 macOS，以上为 Chromium 有效视口模拟，不宣称原生 Windows/Edge 实机测试。未实际付款。

静态前端独立发布，无数据库迁移及支付配置变更；后端保持 3f29929。回滚选择上一静态版本 9ba4743。
