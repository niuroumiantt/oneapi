# API 对比费用与付费模型开放 — 2026-11-17

## 本次要求

开放当前正常可用的模型给付费用户，配置计费并直接出现在对比下拉中；暂停模型不开放。运行后分别显示平台实际消费与参照侧预估费用，明确无法读取客户的官方账单。

## 模型与计费

正式付费白名单为 `deepseek-flash,deepseek-flash-0910,glm-5.3,glm-5.3-flash`。目录还必须通过实时通道可用性、暂停状态及输出成本保护检查；即使白名单仍包含一个模型，暂停或命中成本保护后也不会返回给付费用户。未开放 `deepseek-v4-pro` 和 `glm-5.3-flashx`。

继续走原有付费网关、额度预留、批次消耗、限额和结算链路，不根据页面填写的预估单价收费。现有 Key 的模型范围不被自动扩大；对比使用每次限定所选模型的内部临时凭证。

单价单位均为人民币元 / 百万 Token：

| 平台模型 | 未命中输入 | 缓存命中 | 输出 |
| --- | ---: | ---: | ---: |
| DeepSeek Flash / Flash 0910 | 1 | 0.02 | 4 |
| GLM-5.3 | 8 | 2 | 28 |
| GLM-5.3-Flash | 0.8 | 0.23 | 2.8 |

DeepSeek 高峰按原有规则乘 2，法定节假日沿用现有日历。2026-11-17 已复核 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 和 [GLM 官方价格](https://docs.bigmodel.cn/cn/guide/start/pricing)。Flash 0910 是平台供应商版本，沿用平台 Flash 费率；不将其冒充成已核验的官方独立型号。

## 两侧费用口径

- **平台实际扣额**：读取已结算 `customer_calls`，按该次调用冻结的单价与倍率展示未命中输入、缓存命中、输出明细。推理 Token 属于输出子项，不重复计费。
- **实付消费（购包折算）**：按本次实际使用的每个额度包分别计算 `扣除额度 × 该包实付款 / 该包面额` 后汇总，支持跨不同折扣批次；同时展示现金账本本次记账额。现金以分累计记账，小额调用可能合并记账，不能把记账为 0 分说成免费调用。
- **官方/第三方预估**：使用该侧返回的输入、缓存命中、输出用量，按请求开始时冻结的价格计算。已有核验价格时自动匹配厂商与确切型号，并提供来源与核对日期；第三方不会因模型同名而自动套官方价格。
- 手填单价为人民币 / 百万 Token，明确标注未核验，仅影响预估。未知单价仍可运行；未知单价、缺失完整输入输出用量或失败请求显示无法估算。缓存用量缺失时按全部输入未命中估算并提示可能偏高；缓存写入或存储等额外费用不包含在该三项预估中。
- 明示预计费用不是官方账单，无法读取客户官方/第三方账户真实扣费，实际可能受套餐、缓存、时段、服务档位、工具和价格调整影响，以对应平台账单为准。
- 报告升级 schema v2，包含双方费用、用量、单价快照和说明，继续脱敏 Key。

## 验证

- 独立 PostgreSQL 128 项测试通过，含四个模型逐一走完整对比及结算、暂停/成本保护动态过滤、三折实际消费、跨折扣批次、按分累计、凭证归属、峰谷/节假日、未知和无用量不冒充零费用、手动价格校验。
- 四个真实通道各一条最多 128 输出 Token 的小额调用均 HTTP 200 且流式完成：DeepSeek Flash 8 入 / 1 出；Flash 0910 8 入 / 1 出；GLM-5.3 16 入 / 13 出（含推理 12）；GLM-5.3-Flash 16 入 / 3 出。只验证连通与计量，不是模型身份或性能证明。
- 浏览器使用合成上游和独立账本验证四模型下拉、GLM 自动官方单价、三折折算费用、第三方自填单价、报告导出与 Key 脱敏、桌面和手机布局。正式客户余额未用于该测试。
