# 我的模型操作按钮对齐

个人工作台「备选模型」每行右侧显示「钥匙图标＋一键生成 Key」和「加号图标＋加入模型库」。前者使用主题强调色实底并打开该模型的 Key 配置页，后者使用浅底描边并把模型加入已选清单。两个按钮间距为 10 px。

本地 Chrome 用三个模型数据验证 320、390、560、701、820、1100、1440、1450、1600 px 宽度。两个操作始终同行，相邻列的内容未溢出，两个入口均可正常使用。四套主题下两个按钮的背景均可区分，文字对比度均达到 4.5:1。

个人工作台的「一键生成 Key」只打开专属配置页。打开配置或生成 Key 都不改已选模型清单，加入清单由「加入模型库」或「全选」明确执行。
