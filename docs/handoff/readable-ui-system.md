# 界面字号与布局统一（2026-11-19）

## 范围
修复个人/企业工作台左栏内部 span 覆盖字号的问题；共用页眉主行 64px、工具栏控件 40px、圆角 8px。工作台入口移至登录头像菜单。正文与辅助字号使用共享变量，简化工作台渐变和阴影。充值页提供两种支付标志、微信绿色按钮、折叠付款说明；长内容在单屏框架内滚动。商务/技术后台左栏同步 16px，技术绿色保留。规格见 docs/ui-spec.md。

## 验证
- 隔离 PostgreSQL 下完整回归 167 项通过。
- 合成数据浏览器覆盖 1440×900、1280×720、1920×1080、1024×768、390×844 的个人、工单、充值共 15 个组合，无整页横向溢出，外框高度等于视口。
- 实际登录 Chrome 确认旧版左栏前五项 10px、后三项 13px；临时候选样式后统一 16px。
- Windows 实机不可用；不能将 macOS Chrome 尺寸检查称为 Windows 实测。
- 本次没有修改支付开关、支付逻辑和真实账务数据。

## 发布
候选分支 codex/readable-ui-system。静态资源与两个后台 HTML 都需要发布；生产镜像基线 f180062，静态基线 c5d68b4。发布时只覆盖这两个后台 HTML，不携带其他未部署后端代码。保持微信和支付宝公开开启。
