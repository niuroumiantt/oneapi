# Semifly 统一客户登录交接（2026-11-27，m5）

官网只展示一个客户登录或注册入口。登录后读取已认证账号的 VIP 状态，普通客户默认进入个人概览，已激活 VIP 默认进入 VIP 工作台。明确的模型接入、企业客户空间和邀请或支付链接继续走各自流程。

公司另用 `/staff.html`。公司老板和员工点同一个按钮，复用原有公司身份中心登录和服务端岗位分流。原有工作台业务书签继续有效。前一个版本的四选一首页已由此设计替代。Authentik 的验证流程和授权配置沿用现有部署。

本地用四种示例身份从两个入口走通，核对了普通员工访问老板页面被拦截及退出。登录集成测试与前端回归共 112 项通过。
