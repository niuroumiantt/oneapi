# VIP 申请与员工核验交接

2026-11-24 · m5

- 个人客户注册并登录后进入 `/promotion/vip.html`，填员工邀请码申请。旧 `/cw.html` 跳转并保留查询参数。待确认时申请人看到编号、姓名、提交时间和状态。
- 员工入口是 `/promotion/vip.html?staff=1`。在伙伴列表点「管理」→「查看联系方式」。联系方式加密、按需读取、记录审计。电话查询只返回联系方式，收款资料查询单独要求财务权限。
- 面试确认后发打折码。客户使用打折码单笔实付满 ¥100 后，销售核验到账并确认正式 VIP。确认和发码支持留空备注。工作台顶栏使用共享图标，个人概览通过按钮进入「模型」页。
- 独立 PostgreSQL 环境中 VIP 专项 11 项通过，覆盖待确认、电话权限、财务资料、发码、低于门槛及达标后确认。真实申请人的私密资料和真实付款需在正常业务操作中核验。
- 上海发布按 [部署说明](../deployment/shanghai.md) 执行。用 `/release.json` 和 `/api/status` 对照前后端版本。
