# VIP 累计开通与退款限制（2026-11-25）

## 本轮授权与实现

用户明确要求代码、commit 和主分支上线，并确认已有 VIP 按原付款补记首次 ¥100 不可自助退款限制；不足 ¥100 仅记实际金额，不要求补缴。

- 正常开通按个人账户累计有效净实付 ≥ ¥100。普通充值和 VIP 付款码订单都算；必须有渠道交易凭证、等额充值流水及额度包。赠送、已退金额不算，处理中退款的订单暂不计入。仍由负责销售核验开通。
- 开通事务将最多 ¥100 分配到原单（FIFO），不扣可用额度。已消费的这部分不再形成退款限制，后续无关充值不重复冻结。原单特批记录实际金额。迁移 088 一次性回填已有 active VIP 并记录审计。
- 发票按原实付分配；优先关联已消费现金，避免旧消费发票冻结后续充值。与激活款重叠取并集，不重复扣减。已申请/已开发票部分需先处理发票，不开放管理员绕过。
- 直营折扣码支持单笔实付门槛和不可自助退款条款。默认普通 5 折直接生效；特殊规则由管理员审批。付款前客户必须明确确认，订单保存不可变条款快照和确认时间；旧订单不追溯特殊优惠规则。
- 自助退款退符合条件的现金，收回该单剩余赠送额度，成功后保留受限现金可继续消费。拒绝时完整恢复；退款、用量、赠送过期按账户锁串行。部分退款只取消对应未解锁返佣。
- 管理员在「商务后台 → 收款与退款 → 工单退款特批」核验同一付款账户的未关闭账单工单、填写原因、预览金额并再次确认。销售/普通财务不能特批；客户不能传参数绕过。记录工单、原因、操作者及原单。
- 个人概览红蓝条内显示金额，下面列可自助退金额和排除项。手机大额确认不拆数字。申请指南和客户/销售进度统一累计口径。
