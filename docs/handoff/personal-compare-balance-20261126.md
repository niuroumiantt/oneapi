# 个人 API 对比与红蓝额度条 · 2026-11-26

## 范围

用户继续逐页精简个人工作台，要求 API 对比一页高度，并展示退款相关的红蓝额度条。本阶段完成本地实现与模拟验收，未部署公网。上一公网版本仍为 df185f894a82cce7dd82279071e20419db69e806。

## 实现

- 个人 iframe 使用 `embedded=1&personal=1`，企业及独立对比页面保留现有界面。个人页沿用统一的简洁侧栏和页头。
- 主视图为开始对比、对比结果。开始页只显示账户/双方模型、参照 Key 与共同任务；接口地址、单价、参数、附件、比较说明放入独立设置视图，避免展开撑高页面。
- 小窗口分平台、参照、任务三步。长回答、推理、费用和输入预览分页，保留全文；支持 PDF 和 JSON 导出、参照复测命令。执行与计费仍由 compare.js 原链路负责，运行时锁定已移动的高级输入。
- 结果区将回答、费用、用量与速度、推理与说明分开。平台实付消费和参照预估明确区分，不变更费用计算规则。
- 充值与账单增加红色实付、蓝色赠送额度条；可退金额读取服务端 credit_split.refundable_fen，缺失时只显示查看入口，不以实付剩余冒充可退款。真实退款流程和限制不变。
