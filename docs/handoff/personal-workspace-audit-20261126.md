## 本轮范围

## 实现

- 侧栏顺序：概览、我的模型、API 密钥、用量、充值与账单、支持、API 对比、个人设置、去申请 VIP。商务管理权限入口仍按原权限显示。
- VIP 默认展示「计划介绍」，另有「申请流程」「合作规则」「我的申请 / 我的 VIP」。原申请表、进度、推广码、佣金和资料继续沿用原接口及资格校验；个人模式外的员工和独立申请页面不改。
- 修复 API 对比与 VIP 互切时错误保留旧 iframe：只有目标 src 相同时才复用。
- 修复调用明细的延迟响应覆盖账单/设置等页面：更新前核对当前路由和所属 Tab。
- 概览删除重复的最近调用列表，消费账单入口直接指向消费记录。
- 单屏间距按真实备案页脚校验，收紧概览、模型、对比、账单、退款、发票及 VIP 资料视图；记录继续分页。
- 登录设备原有 SESSION_NOT_FRESH 安全限制不变。将误导性的「暂时无法读取」改为「需重新登录验证」及具体说明，不自动退出用户、不削弱验证。
