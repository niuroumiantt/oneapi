# 个人充值按模型试算交接（2026-11-27，m5）

## 目标

在个人充值页随金额和促销码显示可用官价额度，并在本地验收钱包扣费。

## 已定规则

- 普通充值实付多少，通用钱包就增加多少。通用促销可增加赠送，同一笔到账余额除以各模型销售比例即可估算官价额度，各模型估算不能相加。
- 模型专属码的余额在购买时已折算为对应模型的官价额度。专属包优先用于匹配模型，并沿用购买批次的实付／赠送扣减规则。
- 已配置售价的个人通用钱包按模型销售比例扣费，先扣完各批次的实付，再扣赠送。调用保留官价用量和销售比例快照，账本记实际扣款。

## 进度

- 个人充值页支持普通充值、通用赠送码、模型专属码、无效码和金额编辑。模型购买明细有累计实付、官价到账、已用和剩余小计，以及按购买批次查看的红蓝余额条。
- 本地默认 DeepSeek Flash 8 折、GLM-5.3 8.5 折、GLM-5.3-Flash 8.7 折。无促销码实付 ¥100 试算为 ¥125、¥117.65、¥114.94。测试客户填 PREVIEWBONUS 时赠送 ¥25，填 PREVDZTX 时实付 ¥100 获 DeepSeek Flash 官价额度 ¥200。
- 本地测试库的个人工作台、充值／退款、VIP 分成回归共 82 项通过。浏览器检查 1440×900、1024×768 和 390×844，主要充值内容同屏。矮屏手机可切到「额度试算」。
- 仅本地，未推送、合并或部署。预览使用测试支付与本地账本，真实上游推理及支付未在本轮调用。

## 本地交互跟进

- 本地测试客户已增加一笔 PREVIEWBONUS 模拟订单，实付 ¥50、到账 ¥62.50，用于验证明细。
