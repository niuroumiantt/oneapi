# 供应到客户产品蓝图交接（2026-11-07）

## 本阶段完成

- 用户确认：采购供应商 API Key 与多个型号，平台逐型号展示与定价；客户可选一个或多个型号，人民币余额先充值后消费；个人、企业共用产品模式但钱包隔离；最低充值 ¥5；未用金额可申请原路径退款；平台未来销售自有产品。
- 主文档：[从上游 API 到客户交付](../phase-1/17-supply-to-customer-blueprint.md)，包含供给/商品/客户图、客户旅程、目录字段、资金口径、密钥安全、自有产品分类及落地顺序。
- [客户产品契约](../phase-1/16-customer-product-contract.md)改为主线已确认，明确现有 `demo-*` 数据不能转为真实余额。

## 待下一阶段推进

1. 根据供应商合同与资料确认具体 model ID、转售/品牌/数据权利、采购价、限流与测试条件；实际 key 只走受限内部录入，不出现在文档、工单或聊天。
2. 用真实品牌/型号的非敏感目录替代匿名演示商品；商品可售要经过授权、真实测试与定价审核。
3. 将演示订单与型号解耦为人民币充值订单，把多型号授权、个人/企业钱包、成员预算、调用计量与退款流水实现为真实业务状态机。
4. 15% 退款手续费仅是提案，必须先经法务核对个人和企业适用场景、书面条款与支付渠道能力；不得在网站上宣称为已生效规则。

## 当前边界

公网环境仍是隔离模拟链路；没有真实上游密钥接入、可售模型、收款或推理。本阶段只改产品文档，无部署变更。
