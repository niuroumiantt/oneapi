# 个人工作台空间与首屏布局

基于 main 7bdfa1f，在独立工作树 codex/personal-workspace-wide-20261127 修改。当前为本地预览。

- 个人工作台九个侧栏入口统一内容边距，解除内容区与嵌入页的固定宽度上限。概览的余额和 API 接入并列，图表使用剩余视口高度。宽屏并列已选和备选模型。用量摘要在桌面与记录分栏，充值将账户摘要与付款表单分开。
- 窄屏概览切换额度、API 接入、每日用量、使用状态，模型按已选和备选切换并分页，充值可切换付款与账单余额。消费记录按视口使用 2、3、5 或 8 行，服务端也继续接受旧分页尺寸；导出保留所选日期范围内的全量记录。
- API 对比、VIP 工作台使用宽屏边距。VIP 推广业绩和月账单并排，个人资料、推广码、收件箱与提现入口保持原有路径。
- 本地 Chrome 视口实测 1745×982、1309×727、391×745，九个入口默认页面均无外层或工作区纵向溢出。另检查有余额时的 API 对比、消费账单请求、窄屏分区切换与 VIP 各标签。超短视口、浏览器放大及长文本有原有可访问滚动兜底。
- 个人页面回归 63 通过、4 个库测在该轮跳过。另针对本地 PostgreSQL 复跑额度、账单记录、用量及图表共 11 项，全通过。布局检测无告警。
