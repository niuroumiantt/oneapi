# 金额取整、支付渠道成本与退款口径

2026-11-24 口径校正；原 2026-11-14 文档中的“服务费/特批减免”已随 0 手续费政策废止。

- 面板余额四舍五入至分，精确账本保留；小于一分的累计已用显示“不足 ¥0.01”。退款按红绿模型退红条实付剩余、不收手续费，绿赠送整条收回；金额最终四舍五入到分。
