# 供应商模型市场与请求质量

0.2 更新：[当前两家族目录与 Agent 接入](phase-1/02-models-and-agent-onboarding.md)。本页保留总体业务边界，首期范围以新入口为准。

## 模型和供应商分层

| 对象 | 含义 | 示例说明 |
| --- | --- | --- |
| ModelFamily | 用户识别的模型家族 | DeepSeek、GLM |
| ModelRelease | 具体发布版本及能力 | 版本、上下文、工具调用与计量定义 |
| Supplier | 实际采购合同的对方 | 模型官方或有权提供服务的托管供应商 |
| ProviderEndpoint | 上游接入端点与数据处理路径 | 地区、地址、凭据引用、处理者 |
| SupplierModelOffer | 某供应商提供某版本的采购方案 | 地区授权、成本、限流、SLA、有效期 |
| ModelProduct | 平台面向客户销售的区域商品 | 零售价、数据条件、可售状态与客户限制 |

一款 GLM 模型，通过智谱大陆平台、Z.ai 国际平台或其他获授权供应商提供，是不同采购与数据处理关系。相同模型名不保证相同版本、token 计量、输出质量或数据驻留。

首期只把 DeepSeek、GLM 家族写入固定产品方向。精确模型标识、能力与报价由有来源和审核记录的目录配置提供，不把印象中的旧型号写成“最新”。[S18](11-sources.md#s18)[S19](11-sources.md#s19)

## 供应商准入

生产准入资料包括法人及实际控制关系、合同、转售及下级分销范围、获准客户地区、标准 API 与订阅套餐的区别、处理和留存地点、是否用于训练、子处理者、采购价、账期、速率、争议及事故联络机制。

DeepSeek 和 Z.ai 的公开条款允许一定范围的 API 集成并要求开发者承担下游责任；这一点不能扩展解释为所有跨地区、多级分销和账号密钥共享都获得了许可。拟开展的商业范围须逐项实审，并取得必要书面确认。[S16](11-sources.md#s16)[S17](11-sources.md#s17)

只在凭据系统保存可解密的上游密钥，业务数据库保存引用。供应商管理人员可轮换密钥，但不应默认获得明文读取权。客户 Key 由本平台签发，绝不把采购账号原始 Key 发给客户。

## 供应商质量仪表盘

| 维度 | 应保存的证据 | 运营用途 |
| --- | --- | --- |
| 身份与来源 | 合同、服务产品、实际模型映射、授权有效期 | 确认合法货源和承诺边界 |
| 可用性 | 合格请求数、成功数、超时、429、5xx、流中断 | 判断故障与容量，不用单一平均数掩盖问题 |
| 时延 | 首 token 时延及总时延的 p50/p95 | 区分响应开始慢与生成慢 |
| 协议能力 | 工具调用、结构化输出、流式、上下文测试 | 决定哪些能力可在商品页承诺 |
| 用量成本 | 上游 usage、平台计量、价格版本、账单差额 | 排查重复收费和成本漂移 |
| 输出质量 | 固定样例集、版本、测试时间和评价方法 | 在可复现条件下比较，不以模型自报身份证明来源 |
| 隐私与数据 | 留存、训练用途、子处理者和地域资料 | 匹配客户的数据处理策略 |

展示成功率时写明统计窗口、分母及错误分类。客户参数错误、平台限流和供应商故障分别统计。供应商平均延迟不代替 p95，也不把一次小规模测试当作 SLA。

供应商生命周期为 draft → due_diligence → testing → approved → degraded/suspended → retired。到期授权、无法确认的数据路径或重大计费差异应暂停相应通道。保留历史请求与费用证据以供对账。

## 模型市场页面

模型列表按家族、任务能力、上下文、价格单位、可用地区、数据处理条件过滤。首期仅销售已验证的文本对话、推理及工具调用能力；图像、语音和视频可在数据模型中预留，页面不展示未实现承诺。

详情页说明适用场景、精确版本或别名政策、能力限制、输入/输出/缓存定价、阶梯规则、有效日期、限流和示例请求。价格未确认时显示待配置或联系销售，不显示虚构数字。

支持开发环境试用和受限 Playground。试用额度有上限并遵守相同的地区和内容规则。模型别名升级需要可追溯发布、公告及兼容窗口；对要求稳定版本的企业提供固定版本选项。

## 路由原则

先满足约束，再优化成本。顺序为区域和授权 → 客户数据要求 → 模型版本与能力 → 额度和容量 → 通道健康 → 价格与时延偏好。

首版支持“固定供应商”和“同版本自动备援”两种模式。跨模型家族替换默认关闭；只有客户显式选择时才使用获准的降级方案。客户已收到流式内容后不能把另一家结果无提示拼接进同一回答。

跨境备援默认关闭。在同一获准数据范围内寻找备援；若所有通道均不满足客户约束，返回可解释的不可用状态，不通过绕路破坏合同。

超时后上游是否已执行可能未知。优先使用供应商的幂等能力；对无法确认的请求，不盲目重试并声称不会额外产生费用。每次尝试单独记录、控制次数与费用预算。

每次 ProviderAttempt，包括复用网关内部的重试和备援，都要受已批准通道集合、费用上限和当前停用状态约束。不能拦截或完整观察的自动重试、备援保持关闭。授权快照有期限和策略版本，紧急停用与密钥吊销必须有明确失效检查机制。

## 网关验收门槛

采用前必须用实际获准供应商账号验证：普通与流式响应、工具调用和结构化输出；精确计量映射；断连和缺失 usage；重试与重复事件；额度并发预占；组织与地区隔离；价格/成本对账；通道停用与凭据轮换。

本版完成资料核查和设计，没有执行真实付费调用、压测或供应商商业合同审阅。兼容能力以之后的验收记录为准。
