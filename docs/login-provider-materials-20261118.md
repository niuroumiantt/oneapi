# 微信、支付宝、短信登录接入准备清单（2026-11-18）

## 先统一的资料

1. 确认运营主体：拟沿用“深圳市格洛可半导体有限公司”。提供与该主体一致的平台企业认证；已有账号优先复用，不另开重复账号。
2. 确认正式登录域名：当前 oneapi.glocalstorage.cn 可作为现行入口；如果近期迁到 semifly.ai，请先决定主入口。回调地址、备案、隐私政策和平台审核材料必须对应实际域名。不要把其他公司公众号直接绑定到本主体。
3. 营业执照、公章/授权书（平台要求时）、管理员姓名、手机、邮箱、法人/经办人身份验证，由管理员直接提交给官方平台，不发聊天、不进 Git。
4. 产品名称、简介、Logo，以及实际可访问的首页、登录页、用户协议、隐私政策。技术侧负责页面和回调部署；法定主体、联系人和条款由公司确认。

## 微信

- 以企业主体认证的微信开放平台账号（不是企业微信账号），核实开发者认证和“网站应用”申请状态；完成平台要求的应用审核。
- 提交网站名称、网址、简介、图标及平台当次要求的授权/备案材料。拿到获准用于网站微信登录的 AppID，并通过服务器密钥流程配置 AppSecret。
- 配置登录授权回调域名。具体回调路径由开发完成后提供，不需要你自行猜填。
- 如果要支持“微信内直接登录”，另外核对同主体服务号的网页授权权限和网页授权域名；网站扫码与公众号网页授权不是同一配置。
- 一个能配合扫码确认的微信测试账号。若审核尚未通过，先告知当前状态即可，不能用微信支付商户号替代网站登录 AppID。

## 支付宝

- 已企业认证的支付宝开放平台账号；优先核对现有应用是否能够增加本产品所需的用户授权能力。
- 平台确认该应用类型支持我们需要的“桌面二维码 → 手机授权 → 网站登录”流程；提供能力申请/审核状态及 AppID。不要仅凭支付开通判断登录可用。
- 确认使用公钥模式还是证书模式。私钥由技术侧在服务器生成/管理，管理员把公钥或证书配置到开放平台；已有支付密钥不擅自重建。所需支付宝公钥/证书按当前应用模式配置。
- 配置授权回调地址和平台要求的域名。一个可配合真机授权的支付宝账号。
- 若当前应用不开放此类网站授权，需先由平台确认适用产品/应用类型；不以付款、收款码或未经认可的二维码方式模拟登录。

## 手机验证码（建议先沿用阿里云）

- 企业实名认证的阿里云账号及短信服务资质；营业执照、法人和经办人资料、可接验证码的经办人手机，直接在阿里云提交。按主体归属选自用/他用资质，必要时准备盖章授权书。
- 审核通过且运营商报备状态可用的短信签名 SignName。拟用“格洛可”或品牌名称时，需要相应企业/商标/网站归属证明，以审核结果为准。
- 验证码模板及 TemplateCode：建议注册、登录、密码重置、手机号绑定四个用途；若平台允许统一模板，也必须在服务端保持用途隔离。模板建议“您的验证码为 ${code}，5 分钟内有效，请勿向他人泄露。”，不混入营销内容。
- 发送权限：由管理员配置最小权限 RAM 身份或实例角色，仅允许所需短信发送操作；技术侧负责签名、模板代码和服务器配置。不要提供主账号 AccessKey，不把密钥放聊天。
- 确认短信费用预算/每日发送上限和告警联系人；没有费用授权前不购买套餐或付费开通额外产品。
- 准备 2–3 个获同意用于测试的手机号，尽量覆盖不同运营商。测试应包括注册、登录、找回、绑定、错误验证码、过期及频控。
- 如不需要自定义品牌签名，可评估阿里云“短信认证”托管产品；先确定选普通短信服务还是托管短信认证，二者接入和材料要求不同。

## 可以交给开发处理

回调 URL 的准确值、代码与数据库迁移、二维码会话、state/签名校验、验证码过期/限频/一次性消费、账户绑定、密码校验、旧会话撤销、错误提示、日志脱敏和能力开关。
