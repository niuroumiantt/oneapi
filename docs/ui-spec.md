# 界面共用规格

- 字体：系统中文无衬线，macOS 使用系统/PingFang，Windows 使用 Segoe UI/Microsoft YaHei；代码数据保留等宽字体。
- 工作台左栏 16px，手机 15px；正文 15px，辅助信息 13px。按钮文字继承同级规格，禁止对内部 span 再缩小。
- 页眉主行 64px，工具行控件 40px；手机导航独立一行。共用 `site-header.js/css`，工作台入口仅放在登录后的头像菜单。
- 控件圆角 8px，边框 1px。头像和状态点保持圆形；品牌、语义状态颜色不混用。
- 工作台占一屏高度，页眉、导航、页脚保持位置；长表格与长表单在内容区滚动，不能裁掉按钮或用缩小文字代替布局。
- 工作台背景使用纯色，文字不加阴影或缩放；技术后台保留绿色。
- 支付渠道使用相同尺寸标志与布局，微信绿色、支付宝蓝色；付款说明按需展开，不改变收款、金额或确认流程。
- 验收至少覆盖 1280×720、1440×900、1920×1080、390×844，并检查键盘访问、长内容和放大后的滚动。

## 全站补充（2026-11-19）
- 公开模型目录、文档、Skills、API 对比与后台动态表格同样遵循辅助文字至少 13px；`small` 不使用浏览器默认比例缩小。
- 文档和 Skills 使用视口外框及内部滚动；切页复位对应内容区，搜索锚点仍需可达。
- 缩放验收使用 CSS 视口模拟：1093×615、960×540、768×432，另验 1920×1080 与手机 390×844。此方法验证重排，不代表 Windows 字体栅格化实测。
