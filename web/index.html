上下文和最大输出有什么区别？

上下文是模型一次能处理的内容范围；最大输出是一次能生成的长度。模型官方上限与平台调用上限会分别标明，长上下文不代表一次能输出同样多的内容。

思考模式适合什么任务？

复杂推理和多步分析可以尝试思考模式。思考也会消耗输出预算；简单任务可优先比较成本，选择支持关闭思考的型号。效果需要用自己的任务验证。

模型、额度和 API Key 是什么关系？

充值进入账户，可用于账户已开放的模型。API Key 是接入凭证，一把可以允许多个模型。每次请求用 model 指定其中一个型号，按实际用量扣费。
