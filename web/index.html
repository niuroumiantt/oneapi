HOW PRICING WORKS

官网同型号公开价，
semifly 按八折参考。

先看官方型号与人民币公开价；我们以相同计费项乘以 80% 形成平台参考价。个人与企业共用价格规则，资金分别记账；正式销售须完成供应授权与价格版本审核。

  1. 查看输入未命中、缓存命中、输出价格及适用时段（¥ / 1M Token）
  2. 付款确认后余额入账，再创建限定型号的 API Key
  3. 每次调用记录 Token、费用和剩余余额
