从注册到第一次调用

  1. 注册并验证账号

    使用手机号接收短信验证码，或用邮箱和密码注册。选择邮箱时，打开验证邮件里的链接，验证后进入工作台。

  2. 选模型并充值

    在工作台的「模型」页面确认要用的模型和计费方式，再点「充值额度」。付款前查看实付金额、赠送额度与到账额度，付款后可在账单中核对。

  3. 创建付费 Key

    打开「密钥」，点「创建付费 Key」，选好允许调用的模型。消费上限留空时，默认使用当前未分配额度。创建后立即保存完整密钥，并妥善保管。

  4. 发起调用并核对用量

    在支持 OpenAI 兼容 API 的工具里填入接入地址、你的 Key 和准确的模型 ID。完成第一次调用后，在工作台的「用量」里查看记录。
