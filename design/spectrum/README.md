## 视觉语法

- 大面积浅灰白画布，纯白卡片；主操作用蓝色，青与紫用于类别、趋势、局部强调。
- 文字以深灰黑和可读的灰蓝为主。强调色不能取代语义；成功、待处理、失败、未知有固定配色并带文字/图标。
- 小圆角、细边线、轻阴影。装饰渐变集中在品牌、概览和展示页，工作表格中保持平静。
- 后台用持久侧栏、顶部工作区信息、页标题与主操作、指标、待办、筛选和主表格组织信息。
- 表格数据右对齐、数字等宽、列标题有单位；点击行打开侧边详情，保留筛选和位置。
- 用户主任务对应一个突出的主按钮；其余为描边或文本按钮。危险操作具有独立语义与明确反馈。
- 高密度主要来自布局和路径；不靠缩小到难读的字号。建议业务正文 14、表格 13、标签 12，极次要说明最低基线 11，并按目标平台实际验证。

配色中的主色忠实提取自已确认原型；状态文字颜色和字号是为了迁移可读性而整理的建议值，不声称用户逐个确认过每个数值。原型保留原样供对照。
