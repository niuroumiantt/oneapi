# 交给另一对话：统一 glocal dmg 的视觉与工作台

## 用户任务

用户已经确认 OneAPI 的“珍珠白与光谱色”模型广场及运营后台风格。请将同一视觉语言用于 glocal dmg 仓库中所有相关用户界面，并保持目标产品自身品牌、业务功能和现有技术栈。

这是完整的界面一致性改造，先检查仓库再实施。不要仅生成一张效果图、只修改首页，或把 OneAPI 的业务页面搬过来当作目标产品。

## 开始前读取

1. 本文件及同目录的 README.md、tokens.json、theme.css。
2. 本目录 reference/index.html、reference/styles.css、reference/app.js；需要时本机启动参考页，对照 `#market` 与 `#admin`。
3. 目标仓库 AGENTS.md、项目说明、应用入口、组件库/主题、构建和测试配置，以及现有交接。
4. 确认 glocal dmg 的实际路径、规范仓库名和工作区状态；不要猜成 glocalstorage.com，也不要把 dmg 当成前端框架。

跨机器可从 oneapi 仓库取得 design/spectrum 整个目录，或使用用户提供的 oneapi-style-kit.zip。不能假定另一个对话自动拥有前一对话记忆；私有预览无法访问时直接用本地参考。

不要将浅青、浅紫当作白底小字正文。验证文字、边框、焦点和禁用状态的可辨识性。截图中显得精致的小字不能成为降低实际可读性的理由。

## 工作台结构

适合运营、管理、列表、文件或任务界面的结构为：左侧导航 → 顶部工作区/路径 → 页面标题与主操作 → 必要指标/待办 → 搜索筛选 → 主表格或内容区 → 侧边详情。

只在确有业务意义时使用指标卡和图表；不能为了模仿参考添加虚构数据。普通内容编辑、安装引导、首次使用等页面按自身任务布局，仍使用同一颜色和组件。

列表使用固定表头、清晰排序/筛选、数值右对齐和等宽数字。已有批量操作、虚拟列表、分页、列宽、键盘操作应保留。侧边详情关闭后恢复原筛选、选中行与滚动位置。

## 改造范围与工程方法

1. 清点所有实际路由、窗口、弹窗和共享控件，建立 `页面/组件 → 当前实现 → 改造方式 → 验证状态` 清单。包括首启、登录、主工作台、详情、表单、设置、错误/空白/加载状态，以及仓库中已有的安装或更新界面。
2. 检查是否存在设计 token、UI 组件或原生主题。把本参考映射到已有语义变量；没有统一层时建立小而明确的一层，避免散落硬编码和两套重复组件库。
3. 先统一应用外壳、排版、按钮、输入框、选择器、标签、表格、弹窗和抽屉；使用一个真实代表页面验证实际窗口效果，随后覆盖清单中的其余页面。除非遇到必须用户决定的品牌或功能冲突，否则持续推进。
4. 复用成熟功能，保持真实接口、数据、权限、文件操作、后台任务和导航行为。原型 app.js 只供理解交互，不搬入目标业务实现。
5. 如果是 Electron/Tauri/Web，沿用现有路由和样式方案；如果是 SwiftUI/AppKit，使用原生主题、系统字体和控件。DMG 是交付格式时，保持签名、公证、安装和自动更新流程；不要为改颜色重写应用架构。
6. 品牌使用目标项目自己的名称、Logo 和内容；不带入 OneAPI 的模型名称、供应商、Key、API 地址、促销价格或假账户。也不复制预览顶部“模型广场/运营后台”切换条。
7. 已有深色模式需要继续可用；这份参考只确认浅色方向，深色主题使用目标项目现有语义映射并验证。不要把其他主题下的白色硬编码成新默认。
8. 清理本次替换产生的废弃样式与重复组件，不改与视觉任务无关的业务代码。遵循工作区规则，不覆盖其他未提交工作；需要隔离时从最新远程基线建立规范位置的工作树。

## 验证与交付

- 运行仓库对这类改动要求的构建和检查，覆盖受影响的真实主流程；无需编写仅复制 CSS 数值的测试。
- 检查常用桌面窗口、应用最小支持窗口、系统缩放及已有移动布局；宽表格可在容器内横向滚动，整页不能意外横溢。
- 验证键盘焦点、Tab 顺序、弹窗关闭/焦点恢复、表单错误、禁用/处理中、空/加载/失败/成功、长标题、大量数据及滚动。
- 检查现有功能与权限没有因“隐藏按钮/改布局”而被改变，特别是原生拖拽、文件选择、快捷键和更新入口。
- 按清单交付已改页面、共享组件/token、关键页面截图、测试结果和未完成项的明确原因。不能在只改一页时声称整个仓库已统一。
- 更新目标仓库说明与简短交接，按其流程提交保存；只有产品本身已要求发布时才执行相应发布流程，不把样式提交等同正式上线。

## 给用户的沟通方式

先说明确认到的目标路径/技术栈和改造范围，边检查边推进。集中询问确实影响实施、且无法从仓库推断的问题。保持简洁进度更新，最终给可查看的效果与覆盖情况。
