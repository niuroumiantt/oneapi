# 个人 Dashboard 图表 · 本地设计原型

用户要求先看本地设计，确认后再更新公网。本目录是可交互设计原型，不是已接入真实数据的生产实现。

## 启动

在仓库根目录运行：

```sh
python3 prototypes/personal-dashboard/preview.py --port 4196
```

打开 http://127.0.0.1:4196/#personal 。仅监听本机；所有 API 响应由本地样例生成，写请求拒绝。不要将该服务部署到公网。

## 设计与交互

- 现有个人概览的余额、充值、API 接入继续保留。桌面缩短部分纵向留白。
- 下方左侧每日模型用量：过去 7 天，每个模型固定颜色，堆叠高度是输入 + 输出 Token 总量。悬停、点击或键盘聚焦显示精确值。
- 「展开近 30 天」在原图下面展示完整长图，可收起；含每日数值表。手机长图可横向滚动。
- 右侧使用状态：过去 3 个自然月的滚动窗口，每格一天，绿色深浅按总 Token 分档。方向键在日期之间移动，Escape 关闭提示。
- 手机两图上下排列。预览状态可切换有记录、空态、加载失败；重试返回示例。
- 时间固定为 2026-11-26：周图 11/20—11/26；月图 10/28—11/26；热力图 8/27—11/26（92 天）。样例共 3 个模型，周总量 1,393,000，30 天总量 4,051,700 Token。

## Direction contract

Mode: Operate。沿用现有 personal-home 的白底、灰蓝文字、细边框和系统字族。模型用靛蓝、青绿、金黄区分，使用热力图保留用户截图里的绿色强度表达。

用户先读每日用量与使用频率，再按需打开完整月份；默认不用弹窗打断。周图略宽于热力图，月图展开占一整行。无入场动画，只有悬停、焦点与展开滚动反馈，支持减少动态效果偏好。

## 后续生产接入

确认设计后再实现真实统计。不得把 `demo-data.js` 或预览服务加入公网发布。

- 由认证用户 ID 聚合 `billing_accounts` / `customer_calls` / `customer_api_keys`，排除比较专用 Key。不要用 status 最近调用列表替代完整聚合。
- 按 Asia/Shanghai 的自然日聚合，7/30 天均包含今天，三个月边界需覆盖月底差异。补齐没有使用的日期。
- Token = 输入 + 输出，缓存属于输入，不重复计数；未返回的 Token 不伪造为已知用量。
- 多模型时颜色与 ID 稳定绑定，检查图例换行和长模型名。设计样例仅覆盖 3 模型。
- 接真实 API 后补充加载态、跨账号隔离与边界日期测试；复核真实账号效果，再按用户确认发布。

## 本轮验证

JS 语法检查、样例日期唯一性及合计校验、diff --check 通过。Impeccable detector 无发现。
Chrome 检查桌面 1440×1000、原窗口 1380×610、手机 390×844；7/30 根柱，92 日历格，展开/收起，空态、错误和重试，数值提示、键盘热力图导航、手机横向滚动均已验证。手机页面及卡片无横向溢出。
页面使用原来的内部滚动容器；低高度桌面及手机需要向下滚动查看图表。截图是对应区域的滚动位置，不宣称全部内容在小屏首屏展示。

独立设计复核指出的提示停留和手机月图截图两项已修正/重拍；复核结论为 ship，仅限本地原型与这两项复核，不代表生产就绪。
